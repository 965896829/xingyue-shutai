# 星月书台创作资源入口

总控规则只维护在 `runtime/agent.md`。按当前任务加载对应专项规则，不把本目录全部资源同时放入请求。当前语义映射由 `src/core/creation-policy.ts` 维护；每项操作的工具、输出字段与写入范围由运行期技能合同及宿主提供。

- 阶段及文件位置：`references/workflow.md`。
- 文风和偏好：`references/style-system.md`。
- 人物及连续性记录：`references/memory-system.md`。
- 项目文件格式：`references/templates.md`，模板字段不授权新增设定。
- 实体命名：`references/naming-system.md`，按对象实际世界、时代、文化与类别选择模块。
- 卷名及章名：`references/volume-naming-commercial.md`、`references/chapter-naming-commercial.md`。
- 书名：`title-market-editing/writer.system.md` 和 `reviewer.system.md`。
- 世界、人物、规划、正文、审核及修订：`design-v7/` 中本轮对应操作。

作者当前明确要求和已确认作品声音优先。保留已有作品与历史证据；候选、计划、人物信念及表达样例不等于正式事实。宿主负责资料范围、版本、授权、预算、保存和采纳，模型只使用实际提供的工具完成本轮任务。
