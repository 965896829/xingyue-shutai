# 真实反馈与迭代实验

## 触发与边界

作者提供读者反馈、章间留存、完读/追读或要求做版本实验时使用；模型模拟不替代真实样本。

## 必需输入

授权聚合数据/反馈文本、指标定义、版本、观察窗口、曝光/渠道、同期对照与作者目标。

宿主任务信封、授权与源版本缺失时先读取，仍缺则返回blocked。不能虚构上下文。

## 先读资料

- `../../references/shared-contract.md`

## 执行步骤

1. 先核数据口径：读者是否有机会读下一章、作品版本、章节发布节奏、渠道、样本量和缺失。

2. 反馈按信息不清、人物动机、期待落空、节奏、风格等问题聚类；评论不是事实，也不是自动改稿指令。

3. 定义内部指标而非冒充平台口径，例如同一暴露人群在W天内进入下一章的比例；给分母和时间窗口。

4. 区分相关性与因果；受推荐流量、标签、章节长度或更新时间影响时列混杂因素。

5. 提出单变量、版本绑定的候选实验，离线盲测优先；不能同时换书名/首章/渠道再归因于一句开头。

6. 模型模拟读者仅用于发现潜在误解，结果标synthetic，不报告真实留存提升。

7. 作者选择后调用修订流程；短期流量不能自动推翻主线承诺、角色人格或作品底线。

## 输出契约

遵循shared-contract统一信封。目标产物：

- 11_创作研究/反馈诊断.md
- 实验计划与指标定义
- 限定范围修订建议

路径是changeset目标，实际写入候选区。{chapter}/{start}/{end}由宿主用最少三位章号格式生成，四位及以上不截断。

## 验收与失败处理

- 真实与模拟分开
- 分母/样本/窗口/版本齐全
- 无随机实验不宣称因果
- 隐私数据不外传

发现源hash变化、关键依赖缺失、越权或预算耗尽，返回具体阻断与已完成候选。不自行接受、改写正史或触发外部发布。
