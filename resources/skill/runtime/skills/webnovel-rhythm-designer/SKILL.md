# 批次节奏与回报调度

## 触发与边界

设计3—5章脉冲、检查连续同构、压抑过久、兑现不足或章节强度失配时使用。

## 必需输入

当前范围已接受章节总纲、近章结构特征、题材/读者承诺、未兑现承诺和作者例外。

宿主任务信封、授权与源版本缺失时先读取，仍缺则返回blocked。不能虚构上下文。

## 先读资料

- `../../references/shared-contract.md`
- `../../references/templates/三十章节奏模板.md`
- `../../references/style-system.md`

## 执行步骤

1. 先逐章读取总纲范围；类型或强度冲突优先修节奏，不反向偷偷改章序。

2. 按3—5章聚合为蓄力、变化、兑现、余波单元；每个单元都有内容原因而非机械强弱交替。

3. 分别看压力、关系温度、信息增量和回报类型，不把一条“爽点曲线”当全部读者体验。

4. 检查前两章到当前章的开头机制、施压来源、主角应对、兑现路径与牵引，连续同构要给可行变体。

5. 有意连续高潮只标需审阅的例外，不一律否定；日常和结算保留沉淀但必须改变人物或局势。

6. 首批应证明本书的核心回报承诺；公开打脸只在已确认适用的子类型启用。

## 输出契约

遵循shared-contract统一信封。目标产物：

- 05_长篇大纲/第{start}-{end}章节奏.md
- 重复结构与承诺调度检查

路径是changeset目标，实际写入候选区。{chapter}/{start}/{end}由宿主用最少三位章号格式生成，四位及以上不截断。

## 验收与失败处理

- 节奏覆盖范围等于总纲范围
- 不强迫每章高潮
- 重复判断有结构证据
- 例外带理由

发现源hash变化、关键依赖缺失、越权或预算耗尽，返回具体阻断与已完成候选。不自行接受、改写正史或触发外部发布。

## v3.1 增量

先读 `../../references/memory-studio-v3.1.md`。

保留1—5级强度，计划曲线与已接受正文评估分开。按任务选择压力、回报、情绪、信息和关系维度；不给全部日常章强加高潮。模型标注有证据、量表版本和来源版本，不当真实留存或爆款率。建议变化进入计划候选，不因曲线低就自动重写正文。
