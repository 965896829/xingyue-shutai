# 修订、改名与依赖级联

## 触发与边界

修改已接受正文、设定、名字、人物逻辑、章节顺序或前文事实时使用。先影响分析再按批准范围执行。

## 必需输入

用户修改指令、旧接受版本、作者当前编辑版本、实体ID、依赖图、保护区、授权范围。

宿主任务信封、授权与源版本缺失时先读取，仍缺则返回blocked。不能虚构上下文。

## 先读资料

- `../../references/shared-contract.md`
- `../../references/templates/改动影响记录模板.md`
- `../../references/memory-system.md`
- `../../references/naming/governance.md`

## 执行步骤

1. 确定是纯语言、局部事实、跨章因果还是核心设定变更；记录旧事实与拟新事实，不隐式扩大范围。

2. 从实体与出处查询直接引用和间接依赖，包含后续正文、任务/细纲、记忆、台账、当前进度与索引。

3. 分类需修改、需重新验证、无需修改及理由；历史版本、审阅引文、假名/旧身份时段与明确保留区不可盲替换。

4. 展示影响diff与候选，批准绑定现有基版本及范围；作者改过稿则旧批准过期。

5. 下游已接受正文的修改另需范围覆盖；未修复的相关节点标stale，阻断依赖它们的续写而非停掉无关工作。

6. 修改后重提取受影响事件和记忆，重算来源位置与hash，检查新旧矛盾；只对实际受影响内容提交。

7. 保存修订闭环记录与回滚点；执行失败明确列未同步区，不能称全书一致。

## 输出契约

遵循shared-contract统一信封。目标产物：

- 09_续写状态/改动影响记录.md
- 影响图与changeset
- 必要的正文/计划/记忆候选

路径是changeset目标，实际写入候选区。{chapter}/{start}/{end}由宿主用最少三位章号格式生成，四位及以上不截断。

## 验收与失败处理

- 无全书无差别替换
- 旧批准不能覆盖新手稿
- 历史别名保留
- 下游闭环或明确stale

发现源hash变化、关键依赖缺失、越权或预算耗尽，返回具体阻断与已完成候选。不自行接受、改写正史或触发外部发布。
