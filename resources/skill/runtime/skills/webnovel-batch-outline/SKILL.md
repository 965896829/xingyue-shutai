# 完整批次细纲

## 触发与边界

将已确认章节总纲和节奏转为当前批次可执行细纲时使用，默认完整30章，末批实际截断。

## 必需输入

匹配范围的总纲与节奏及其hash；分卷、角色/连续性状态、揭示预算与已接受偏差。

宿主任务信封、授权与源版本缺失时先读取，仍缺则返回blocked。不能虚构上下文。

## 先读资料

- `../../references/shared-contract.md`
- `../../references/templates/三十章批量细纲模板.md`
- `../../references/memory-system.md`

## 执行步骤

1. 拒绝无总纲或节奏版本的直接批量细纲任务；先请求补齐依赖或获得适用授权。

2. 批次层写范围、依据、当前卷、主目标、终点、揭示总量、禁止提前揭示、强度与重复检查。

3. 逐章保留原12项：承接、类型、强度、入口、场面、动作、外推、状态、揭示、回报、记忆变化、牵引。

4. 保证细纲可执行：谁在何地基于什么信息做什么，付出何种代价，留下何种实际后果。

5. 相邻章接力检查物品、伤势、时间和知情；临时创意先写候选设定，不偷偷扩正式世界观。

6. 完整覆盖后才可进入主线单章写作；未完成的批次保留进度，不虚报完成。

## 输出契约

遵循shared-contract统一信封。目标产物：

- 06_章节设计/第{start}-{end}章细纲.md

路径是changeset目标，实际写入候选区。{chapter}/{start}/{end}由宿主用最少三位章号格式生成，四位及以上不截断。

## 验收与失败处理

- 总纲/节奏/细纲版本一致
- 批次实际覆盖完整
- 类型强度同步
- 只计划不污染事实

发现源hash变化、关键依赖缺失、越权或预算耗尽，返回具体阻断与已完成候选。不自行接受、改写正史或触发外部发布。
