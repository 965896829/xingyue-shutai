# 单章任务与场面细纲

## 触发与边界

准备某章正文、续写或对单章重设计时使用；从适用批次细纲细化，不重新凭空编排。

## 必需输入

本章批量细纲、上章接受正文、相关记忆证据、项目配置、已启用文风、本章授权。

宿主任务信封、授权与源版本缺失时先读取，仍缺则返回blocked。不能虚构上下文。

## 先读资料

- `../../references/shared-contract.md`
- `../../references/templates/章节任务清单模板.md`
- `../../references/templates/章节细纲模板.md`
- `../../references/style-system.md`

## 执行步骤

1. 调用context-retriever核对不可改承接、人物当前动机、受限伤势、物品、期限和知情。

2. 保留任务清单全部字段，目标字数和POV从锁定配置读取，首次名词与线索含义写清。

3. 将章节拆为符合类型的若干场面，不强制五段；每场面给目标、阻力、选择、结果和信息边界。

4. 明确主角有效选择、至少一项终章状态变化、主要阅读回报和软/硬牵引。

5. 写本章揭示预算与禁止提前解释；章末隐藏动机/后续，不隐藏线索基本意义。

6. 可选给场面长度预算以辅助控制字数；不把预算当正文已写计数。偏离批次计划则先输出差异。

## 输出契约

遵循shared-contract统一信封。目标产物：

- 06_章节设计/第{chapter}章任务清单.md
- 06_章节设计/第{chapter}章细纲.md

路径是changeset目标，实际写入候选区。{chapter}/{start}/{end}由宿主用最少三位章号格式生成，四位及以上不截断。

## 验收与失败处理

- 不可改承接已核对
- 场面有因果非纯描述
- 新术语有白话锚点
- 没有偷改批次计划

发现源hash变化、关键依赖缺失、越权或预算耗尽，返回具体阻断与已完成候选。不自行接受、改写正史或触发外部发布。
