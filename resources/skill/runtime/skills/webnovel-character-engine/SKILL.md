# 人物能动性与关系动力

## 触发与边界

建立角色卡、关系网络、角色动机、反派行为或修复人物崩坏时使用。

## 必需输入

已确认配置/世界；已有角色ID、关系与出处；当前批次目标。

宿主任务信封、授权与源版本缺失时先读取，仍缺则返回blocked。不能虚构上下文。

## 先读资料

- `../../references/shared-contract.md`
- `../../references/memory-system.md`
- `../../references/naming/common.md`
- `../../references/templates/连续性台账模板.md`

## 执行步骤

1. 保留角色卡全部原字段，不因模板自动制造女主、三级反派或围观夸奖角色。

2. 为重要角色建立稳定ID、本名/别名/称谓规则、外在目标、深层欲望、恐惧、行动方法与当前压力。

3. 给角色一次能区别于其他人的选择：原则与利益冲突时舍什么、何时改变、代价是什么。

4. 关系既可合作又可不信任；必要时区分双向态度。信任分仅作者编辑量表，没有自动每救一次加20分。

5. 反派/搭档各有目标与信息限制；聪明角色会更新策略。惊讶与赞叹不能是搭档唯一作用。

6. 初始记忆和实际正文事实分开；未来情绪转折先写计划，不冒充已发生变化。

## 输出契约

遵循shared-contract统一信封。目标产物：

- 04_人物记忆库/角色卡.md
- 04_人物记忆库/人物关系.md
- 人物行为与连续性台账初始化候选

路径是changeset目标，实际写入候选区。{chapter}/{start}/{end}由宿主用最少三位章号格式生成，四位及以上不截断。

## 验收与失败处理

- 角色行动可由动机和知情解释
- 稳定ID不因改名变化
- 没有同名盲合并
- 未发生事件不写成历史

发现源hash变化、关键依赖缺失、越权或预算耗尽，返回具体阻断与已完成候选。不自行接受、改写正史或触发外部发布。
