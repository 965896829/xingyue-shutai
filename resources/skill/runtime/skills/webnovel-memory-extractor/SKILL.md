# 章后候选记忆差异

## 触发与边界

正文候选定稿后提取实际发生事件、角色状态和连续性变化，形成待接受差异；不自行写入正史。

## 必需输入

复读后的正文候选或已接受版本及hash；旧快照；提取范围；实体及五类台账。

宿主任务信封、授权与源版本缺失时先读取，仍缺则返回blocked。不能虚构上下文。

## 先读资料

- `../../references/shared-contract.md`
- `../../references/memory-system.md`
- `../../references/templates/章后更新模板.md`
- `../../references/templates/连续性台账模板.md`

## 执行步骤

1. 根据正文而非细纲提取实际事件；每项变化带source_ref、主体ID、原值/新值及事实种类。

2. 对话谎言记为说过什么，转述/推测/误解单独建认知记录；计划和作者后台真相不当已发生。

3. 只处理本章实际出场或状态变化角色；既未出场又未变化则不重写。

4. 依次提议角色当前字段、关系、活跃行为、五类台账、读者已知与承诺差异；无变化有原因。

5. 正文实际字符数必须取保存文件的确定性计数结果；章后“已同步”字段保持待提交，宿主成功回执后才物化是。

6. 与正文及依赖组成整体changeset供批准；正文后续变动使差异过期，必须重提取或验证。

## 输出契约

遵循shared-contract统一信封。目标产物：

- 08_章后更新/第{chapter}章记忆更新.md候选
- memory delta
- 09_续写状态/当前进度.md与索引候选

路径是changeset目标，实际写入候选区。{chapter}/{start}/{end}由宿主用最少三位章号格式生成，四位及以上不截断。

## 验收与失败处理

- 每个关键事实有原文出处
- 无计划污染
- 不对全部角色假更新
- 未提交不标已同步

发现源hash变化、关键依赖缺失、越权或预算耗尽，返回具体阻断与已完成候选。不自行接受、改写正史或触发外部发布。
