# 世界规则与长篇动力

## 触发与边界

设计或审核世界规则、金手指、资源/力量体系、限制代价和对手反制时使用。

## 必需输入

已确认设定与配置；规则台账；当前命名空间；既有正文证据。

宿主任务信封、授权与源版本缺失时先读取，仍缺则返回blocked。不能虚构上下文。

## 先读资料

- `../../references/shared-contract.md`
- `../../references/naming/common.md`
- `../../references/templates/连续性台账模板.md`

## 执行步骤

1. 每条世界规则写触发条件、结果、边界、代价、谁知道及能产生的剧情选择。

2. 分别维护世界真实规则、公众认识、主角理解和读者目前可知，不因后续揭示误改原有世界事实。

3. 金手指若适用，设计主角掌握与对手学习路径；新的限制必须有已知边界或合理伏笔，不为临场卡主角硬加规则。

4. 设置资源约束、关系代价或目标冲突等持续引擎；没有金手指的作品同样可以靠职业、谜案或人物选择持续推进。

5. 反复问同一能力第20次使用为何仍有新选择；变化来自利益、信息、责任或对手，不仅是等级更高。

6. 首章只分配当前冲突需要的最小信息切片，余下进入计划揭示表；命名从世界语境来，不倒过来补世界解释名字。

## 输出契约

遵循shared-contract统一信封。目标产物：

- 03_世界规则与卖点/世界规则与卖点.md
- 规则/揭示预算候选

路径是changeset目标，实际写入候选区。{chapter}/{start}/{end}由宿主用最少三位章号格式生成，四位及以上不截断。

## 验收与失败处理

- 规则能落成事件
- 有界而非万能
- 新限制不任意作弊
- 已发生与未来揭示分离

发现源hash变化、关键依赖缺失、越权或预算耗尽，返回具体阻断与已完成候选。不自行接受、改写正史或触发外部发布。
