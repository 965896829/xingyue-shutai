# 项目级文风分析与启用

## 触发与边界

用户提供本人写作样本、明确风格描述或要求调整叙述声音时使用；启用状态需宿主确认。

## 必需输入

用户样本或描述及权限；当前文风状态；配置POV/字数/类型；实际场景集合。

宿主任务信封、授权与源版本缺失时先读取，仍缺则返回blocked。不能虚构上下文。

## 先读资料

- `../../references/shared-contract.md`
- `../../references/style-system.md`
- `../../references/templates/文风样本与规则模板.md`

## 执行步骤

1. 标注来源是用户样本、用户描述还是项目默认；无样本不造样本结论。

2. 逐项分析叙述距离、句式节奏、用词、镜头、人物表现、对话、信息讲解、情绪、回报与章末方式。

3. 只迁移语言和叙事方法，不搬用样本原句、专名、人物关系或剧情；对未覆盖场景明确写推导建议。

4. 记录必须保留和不应继承的病句、重复、逻辑问题及无效铺陈；不为套模板强加战斗/审判等场景。

5. 给简短的同事实表达对比用于作者判断，不改剧情结果和信息预算。

6. 输出未启用的档案候选；宿主接受启用后后续任务/细纲/正文/修订才能应用。旧启用版本保留可恢复。

## 输出契约

遵循shared-contract统一信封。目标产物：

- 02_项目配置/文风样本与规则.md
- 文风版本与样本来源映射

路径是changeset目标，实际写入候选区。{chapter}/{start}/{end}由宿主用最少三位章号格式生成，四位及以上不截断。

## 验收与失败处理

- 未启用不覆盖配置
- 源样本hash与启用范围齐全
- 推导规则有标注
- 不能以去AI味删除必要解释

发现源hash变化、关键依赖缺失、越权或预算耗尽，返回具体阻断与已完成候选。不自行接受、改写正史或触发外部发布。
