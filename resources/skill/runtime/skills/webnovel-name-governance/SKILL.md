# 全题材命名与改名保护

## 触发与边界

出现任何新名称、作者起名、名称审查或改名时使用。新候选纠错与已接受名称保护必须分开。
不能单独授权全书替换；题材标签不能强行决定角色关系。

## 必需输入

命名对象类型、时代/地域/文化、世界/时间线、命名者、实体ID、确认状态、视角知情、禁用约定。

宿主任务信封、授权与源版本缺失时先读取，仍缺则返回blocked。不能虚构上下文。

## 先读资料

- `../../references/shared-contract.md`
- `../../references/naming/common.md`
- `../../references/naming/governance.md`

## 执行步骤

1. 先读common与governance，再按对象实际背景加载相关G模块和必要T模块；模块索引不是候选池。

2. 区分人物、组织、职位、建筑、物品、能力、等级、地点、事件和书名，不能拿后缀替代实体类型。

3. 先核已有名/简称/别名/授权；命名所缺设定可用临时描述，不为好听擅自补机构或文化。

4. 新候选检查作者禁用项、语境、读音形近、首见可理解和视角泄密。反例出现于审阅资料不代表书中要使用。

5. 含司/使的名称按时代制度审查，保留真实历史官署、阴司条件例外与现代正常部门，不做逐字禁词器。

6. 已接受改名先生成旧/新名称、实体、时段、涉及引用、必须保留的假名/旧身份和影响清单；批准后交revision-cascade。

7. 只要求正文时不夹带命名评分。未检索不宣称全网唯一，审校通过不等于作者接受。

## 输出契约

遵循shared-contract统一信封。目标产物：

- 名称候选或审阅报告
- 实体别名台账差异
- 必要的改名changeset提案

路径是changeset目标，实际写入候选区。{chapter}/{start}/{end}由宿主用最少三位章号格式生成，四位及以上不截断。

## 验收与失败处理

- 无示例污染
- 旧稿未经授权不改
- 混合世界分别路由
- 历史别名和不知情角色称呼不乱替换

发现源hash变化、关键依赖缺失、越权或预算耗尽，返回具体阻断与已完成候选。不自行接受、改写正史或触发外部发布。
