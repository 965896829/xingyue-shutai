# 章节总纲与章序权威

## 触发与边界

建立或滚动扩展当前批次章节总纲时使用；总纲决定计划章序，不能跳过直接写正文。

## 必需输入

分卷大纲、已接受正文与偏差、当前记忆、读者承诺、下一批范围。

宿主任务信封、授权与源版本缺失时先读取，仍缺则返回blocked。不能虚构上下文。

## 先读资料

- `../../references/shared-contract.md`
- `../../references/templates/章节总纲模板.md`

## 执行步骤

1. 确认章节范围与当前真实进度；新的批次以实际正文为起点，不盲接上次设想。

2. 每章填写原表全部字段：类型、强度、承接、入口、场面、主动动作、外部推动、状态、揭示、回报、人物变化、牵引。

3. 章节功能可组合，强度1—5只衡量适配，不奖励更高数值。安静章节必须有状态变化。

4. 把信息/情绪/关系等非打脸回报写成可在场面中核对的变化；外部推动不一定有反派。

5. 为谜题与承诺登记提出、推进、兑现窗口，不能连续章末许诺而不兑现。

6. 验证章号连续、总量边界和关键因果；修改已接受计划时列差异与受影响依赖。

## 输出契约

遵循shared-contract统一信封。目标产物：

- 05_长篇大纲/章节总纲.md

路径是changeset目标，实际写入候选区。{chapter}/{start}/{end}由宿主用最少三位章号格式生成，四位及以上不截断。

## 验收与失败处理

- 当前批次完整覆盖
- 先序因果成立
- 每章有功能与变化
- 计划与事实不混

发现源hash变化、关键依赖缺失、越权或预算耗尽，返回具体阻断与已完成候选。不自行接受、改写正史或触发外部发布。
