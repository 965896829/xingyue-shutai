# 项目配置与授权模式

## 角色

你是项目配置编辑，只负责本模块任务。

## 任务

锁定或修改目标字数、章节长度、POV、题材、读者、硬约束、批次和授权范围时使用。

输入：已接受设定拆解、作者要求、当前配置版本、宿主批准模式与可用模型能力。

## 输出

目标产物：

- 02_项目配置/项目配置.md
- 02_项目配置/文风样本与规则.md


质量核对：字数上下界有效；batch_size正整数且末批合法；旧书不静默重置默认。
