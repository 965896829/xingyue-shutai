# 分卷命名：从真实目录到本书的叙事口吻

适用于生成分卷大纲或作者明确要求修改卷名。卷名是给读者看的标题；容量、阶段功能与情节说明仍按原模板完整填写。不要把书名的营销句式、正文的说明规则或机构命名规则直接当卷名模板。

## 先确认题材，再看目录

- 以作者原始创意、已确认方案、世界与人物为依据。旧配置里的宽泛分类不能盖过已经确认的故事；都市求生不能因为配置残留“玄幻脑洞”而检索修仙系统文。
- 实时参考必须来自本次实际搜索并读取的番茄官方作品目录。只查公开题材词，不把私有稿件、角色姓名或未公开设定发给搜索服务。保存书名、作者、官方链接、核对时间、分类与真实卷名；区分检索时间和作品更新时间。
- 客户端已提供 `volumeNamingReference` 时复用它，不再调用搜索或要求作者另行审核资料。在 Codex 等直接执行 skill 的环境中，没有该资料时完成一批检索：最多两次不同查询，最多读取三本候选书的官方目录，然后进入大纲创作。读取失败如实说明，不连续重搜。
- 只有书名、简介、搜索摘要或模型记忆不算核实卷名。排除关键词聚合页、同名仿作混淆、默认卷与正文卷；不要拿章名冒充卷名。少于两个实际命名分卷的书，不用它推断整组卷名风格。
- “出现在番茄”只证明出处，不证明值得模仿。结合分类、简介和实际目录挑选表达自然、有辨识度、适合本书读者的样本。区分同题材可借鉴、相邻题材仅借语气、无关或模板化应排除；可以全部不用，不为凑数学习劣质表达。样本不足或联网关闭时使用以下方法，但不能声称完成实时参考。

## 命名在同一次大纲创作内完成

1. 先有完整的各卷故事弧。对每卷找出最值得读者记住的核心：一次不可撤回的选择、一段关系的变化、贯穿该卷的独特事物或场面、角色会说出口且会被情节重新解释的话。不要仅把阶段目标缩短成标题。
2. 比较可用目录的表达方法：人物口吻与态度变化、意象与剧情的对应、专属地点或事件的分量、整组如何递进。学习这种联系，不复制原作句子、专有名词或整套结构。相邻类型的神明、异能、重生等不能因此进入本书。
3. 从本书的故事里长出名字。可以直接、有悬念、有情绪，也可以简短含蓄；不强制四字、不统一套“某某之战”、不把每卷改成口号或反问。一个有力的具体事件名可以成立，空泛的诗意词也可能失败；判断的是这个名字为何只适合这一卷。
4. 整组连读应有同一本书的气质和阶段变化。前卷不抢泄后卷真相；不要八卷都用同一种句式、同一副宏大腔调，也不要为了变化混用互不相干的文风。
5. 提交前在本轮内筛掉可以原封不动换到任意小说的通用套话，以及必须依赖长篇解释才成立的名字。确认它由现有剧情支撑，读者能感到人物、处境或期待。保留必要的信息密度，不为“去AI”刻意晦涩。

以下是方法辨析，不是可照抄的名字库，也不是新书必须走的路线：

- 2026-10-27 核对《十日终焉》的官方目录，节选“我听到了你们”“我很失望”“准备认输了吗？”。可观察说话者的态度与关系推进；不能把全部作品都写成这种对话连句。[原作目录](https://fanqienovel.com/page/7143038691944959011)
- 同日核对《我在精神病院学斩神》，节选“凡尘神域”“深红夜幕”“神陨乐章”。可观察书内意象与阶段情绪的联系；都市高武的神话尺度不能套给普通人抢修求生的故事。[原作目录](https://fanqienovel.com/page/6982529841564224526)
- “有水之后”“留下来的记录”容易只剩模糊的前后关系；“水厂争夺战”虽然说清了事件，也不能仅凭明确就认定风格合格。应结合本卷真正的人物处境与记忆点判断，不能用同义词替换当作改进。这些是待改示例，不是禁词表。

## 输出与修改边界

- 沿用 `分卷大纲模板.md` 的容量表和逐卷字段。容量表的“卷名”与对应卷标题必须相同。来源、研究说明和候选名比较由任务记录承载，不混入正式大纲，也不新增逐卷命名解释、评分表或审核回执。
- 一批目录资料服务整组卷名；后续同批修订复用，不为每卷另开请求，不增加独立命名审查轮次。“像不像”不是机械格式阻断条件；作者直接看大纲、表达偏好并交流修改。
- 作者只要求改卷名时，只改容量表的卷名格和对应卷标题；保留章数、章节范围、剧情、人物、规则和伏笔，不为迎合一个名字重写故事。作者已确认的名称，未经要求不得重命名。
