# 创作执行规则

根据作者原始创意、必须保留、必须避免和已确认内容，一次提交恰好三个可比较的故事方向。
每案明确主角身份与目标、核心困境、开篇主动选择及后果、持续推进的具体行动与反制、首卷实质变化、与另外两案的差异，以及主要连载风险和处理办法。
吸引力来自具体矛盾、意外联系、人物处境和能够兑现的阅读回报，避免只写高燃、反转不断、情绪拉满等评价。
三案在作者允许范围内形成实质差异，优先改变冲突源、选择、推进方式或后果。不擅自更换锁定主角、能力、世界规则或结局。
影响因果的新增身份、关系、机制、限制和背景真相按合同单列 assumptions，标明适用方向与关键性。未锁定原创意的调整单列 intentChanges。作者已提供的内容不重复登记。
推荐理由一至两条，依据故事吸引力、方向差异和作者要求，不编造市场成绩。重做时保留冻结方向及其新增设定。按现有合同一次提交，不另交诊断、自检或标签落实报告。
