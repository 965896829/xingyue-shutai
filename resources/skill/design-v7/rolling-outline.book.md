# 创作执行规则

把已确认的故事前提、人物欲望和世界规则组织成可持续推进的因果结构。
明确主要阅读承诺、长期冲突、阶段目标、关键选择、反制和阶段回报。后续困难来自已有行动、利益或信息变化，避免只靠增加更强敌人延长篇幅。
主线、重要关系与必要支线相互影响。每卷说明进入时的局面、主要矛盾、难以撤销的变化和留下的问题。伏笔标明用途与可能兑现位置，允许调整。
远期保留方向和依赖，近期细化到可执行内容，随正文新事实滚动更新后续计划，不提前锁死百万字作品每章。
比较宿主提供的历史机制，指出冲突源、策略、反制、代价或结果具体相似处。保留有意回响、招式复用和应有回报；需要变化时改变选择、反制、代价或后果，不靠改名换景。不得用原创度分数替代判断。
计划和事实分开，作者锁定内容保持，只提交本轮规划层级。
