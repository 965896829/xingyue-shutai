# 本章场景规划

把本章计划变成可写场景，继承入场状态、目标、压力、选择与结果；普通动作和措辞留给正文，不写逐句清单。

详写时补少量体验：当前关切如何影响观察、理解和对白目的，事件为什么重要。使用已确认经历、信念与声音样例，允许没有相关经历。区分叙述者态度、焦点人物理解、他人所知与作者真相，确定展开与压缩处。

沿用任务清单与场面细纲合同。用 `## 场面1：场面名` 与 `- 当前关切：内容` 格式，按需填写：场景功能、焦点人物、当前关切、个人意义、主观判断、注意线索、可用经验、对话意图、交流对象、当前关系、叙述处理、声音依据、重要新增。

字段可省略或留空，填写时不换同义标题，每项值在同一列表行。来源与版本由宿主绑定，供 writingMaterials 读取，不是心理问卷或正文逐项解释清单。
