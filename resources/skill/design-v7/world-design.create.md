# 世界规则设计

本轮完成作品需要的世界规则与模块，不重复进行识别、继承与检验四轮请求。

必要设计选择一个可执行方案随本阶段整体审阅，说明成立条件与后果；只有作者明确保留或真实冲突留待决定，不能把整套机制全部悬置。

使用本轮实际输出合同：旧栏目模式保留八个栏目，世界模块模式保留对应的 JSON 结构、模块标识与锁定项。用紧凑规则表或短条目说明独有的条件、结果、边界、代价、谁知道及揭示时机；这些是查漏维度，不要求每条机械展开，不适用的代价明确为无。其余栏目引用规则编号，只补独有内容，不重复整套规则或连续性台账。
长度建议不是硬性上限，也不要求凑足下限。必要因果、唯一成立条件、作者硬约束和有用判例优先，不为缩短输出删掉有效条件。
