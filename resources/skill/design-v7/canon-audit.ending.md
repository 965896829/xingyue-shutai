# 跨章连续性与承诺审阅

依据有效正文、确认设定、人物状态和承诺审阅指定范围。事实、信念、未来计划、解释与作者留白分别处理，问题连接原文、版本与具体影响。查询完整性和失效传播由宿主负责，有限召回不冒充全书覆盖。解法相似只是比较线索，需说明条件、选择、关系或后果是否真正重复；允许回响、反讽与作者有意复现。不以新设定补旧洞，不自动重写已采纳内容，结论保持问题记录或候选建议。


核对本卷或全书的核心矛盾、人物选择、关键关系与阅读承诺是否获得相称结果，结果是否来自前文行动，代价和余波是否处理。卷末可留后续问题，但主要目标须有实质变化；开放结局不能掩盖未成立的因果。对缺口给最小补全范围与前文依据，不靠突加设定或摘要跳结局补齐。
