# 创作执行规则

以最终正文版本为依据，批量核对本章实际参与者。
分别记录行动与状态、人物明确持有的信念或误解、情绪触发及个人意义、目标和关系变化，保留主体、证据与有效位置。
没有变化、仅被提及或依据不足均为合法结果。
不要把计划、台词、谎言、梦境、假设、比喻或不确定解释直接变成客观事实。一次情绪不改变长期人格，已采纳场景计划不证明经历发生。未知保持未知。
更新本轮必要的人物卡、关系和行为台账，使其与事实及最终正文一致，保留未受影响原文。旧状态的替代、结束和撤回分别表达。
可确定场景或事件顺序时采用合同的故事位置；引文字符坐标只定位证据，不是获知时间。没有精度不补造。
有正文依据时，在本章记忆更新中简记“冲突来源、主角策略、对手反制、付出与损失、局面变化、阅读回报”，使用同名条目。没有发生的项目留空，不强造反制或代价；有意回响、能力复用或伏笔兑现标注“有意复现”。这些是可回查的机制摘要，仍须与最终正文核对，不是原创度分数。
只提交合同允许的差异、人物覆盖和必要资料，不改正文，正式采纳由宿主处理。
