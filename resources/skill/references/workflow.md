# 当前长篇创作流程

本文件说明阶段与产物，具体创作规则由运行期按阶段加载，不能由模板反向推定作者的题材、文风或世界设定。生成、审核、采纳与推进由宿主管理；已有明确授权不重复询问，未授权范围不扩大。

| 阶段 | 工作 | 主要产物 |
| --- | --- | --- |
| S01 | 提炼已确认前提、主角困境、开篇选择与长期动力 | 01_设定拆解/设定拆解.md |
| S02 | 同步题材、篇幅、视角、文风、读者与作者约束 | 02_项目配置/项目配置.md、文风样本与规则.md |
| S03 | 按作品需要设计世界规则，支持无体系、多体系与自定义 | 03_世界规则与卖点/世界规则与卖点.md |
| S04 | 建立实际需要的人物、关系、行为及连续性资料 | 04_人物记忆库/ 与 04_连续性记忆库/ |
| S05 | 安排分卷目标、冲突、选择、阶段变化与兑现 | 05_长篇大纲/分卷大纲.md |
| S06 | 形成可滚动调整的章节因果路线 | 05_长篇大纲/章节总纲.md |
| S07 | 安排当前批次压力、回报、日常与余波 | 当前批次节奏文件 |
| S08 | 为当前批次形成可执行细纲 | 当前批次细纲文件 |

开书入口可先比较三个方向、展开选定方案并生成书名；方案已经完成的设定拆解不再重复生成。默认章后流程复用正文审核、记忆提取与记忆审核，不为每个人物建立常驻 Agent 或固定润色轮。

目标章节、所属批次、世界、时间线、视角与人物知情范围使用宿主本轮任务范围；修改历史章不顺带改变当前创作进度。资料缺失时指出具体缺口，不用其他章替代。

篇幅与批次采用作者已确认配置，章数向上取整、末批按实际余量。模板的“金手指”“代价”“反派”等栏目只在适用时填写，不强制所有作品存在这些元素。没有依据的状态保持未知，无变化、仅被提及与证据不足都是合法记忆结果。

正文、人物资料与核心事实同版本核对和采纳。旧状态被替代不抹去其原有效时期；错误记录撤回后不能恢复成历史事实。故事位置与编辑历史分别查询。批次结束后由宿主归档行为记录并安排下一批，模型不自行改正式进度。
