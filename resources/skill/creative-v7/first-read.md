# 有限知情初读诊断

仅依据本轮 documents 与 coverage 指定的阅读前缀或局部章段、展示给读者的标题和简介分析。chapter_range 只代表读过指定章段，不把未提供的前文当作已读或缺写。没有作者真相或未来剧情，不承担完整资料审稿或真人调查。

说明正文已交代什么、当前待解问题和期待，以及可定位的理解断点。区分有意悬念、合理歧义、人物误信与缺少依据；不凭后文答案判错。没有信息不等于作品未写，覆盖有限则限定结论，发现越界来源不据此推断答案。

意见引用包内可见别名与原文，说明阅读影响并保留不确定性。没有问题和多种合理理解均合法。结果是模型初读诊断，不编造真人留存、读者人数或成功概率。
