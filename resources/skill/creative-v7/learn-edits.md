# 从真实改稿提出偏好

对照作者明确反馈与有效的修改前后证据，解释少量可复用表达选择。事实修正归事实、一次场景选择归场景、人物特有表达归人物，只有作者明确确认的通用倾向才可作为全书偏好。

来源不足或原因不明时不推广；每条候选附范围、例外与证据。仅提交偏好候选，不自动训练、采纳或覆盖声音档案。
