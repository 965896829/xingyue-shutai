## 2. 冲突与处理

| 检查项 | 原有风险或差异 | 本次处理 |
| --- | --- | --- |
| “司、使”及现代机构词 | 总控没有明确限制只适用于缺乏对应背景的东方幻想，容易与新版历史、现代分类冲突 | 将总控和工作流入口改为按实际年代、文化、制度判断；正常历史职称、现代机构、阴司等条件例外不按单字禁用 |
| 法器反例 | 反例容易当成候选；又可能被扩大成“所有功能性名称都不许用” | 保留新版明确禁用三个新名称的规则，同时保留照魂镜、正常设备名称等语境例外；不把反例推成新增世界体系的依据 |
| 混合题材 | 用一个主分类给现代医院、古老宗门或快穿世界套同一套词汇 | 通用规则常驻，分类与标签可组合读取；最终按对象实际所属世界与语境判断 |
| 规则装配 | 旧实现每次注入整份命名文档，新文件 43,473 字节会携带大量无关示例 | 先预载明确匹配的模块，提供完整模块索引及只读规则工具；不把所有分类和验收故事放入首次请求 |
| 未知入口 | “纯爱”“奇幻仙侠”“悬疑恋爱”等不能简单等同具体世界或人物组合 | 保留新版入口兼容规则；无法精确映射时使用 G37 与通用规则并标明未知，由模型依据作品资料补读，不自动猜成玄幻 |
| 旧任务与新规则混用 | 未预载模块被修改，也可能影响后续命名 | 完整规则文件哈希进入任务规则哈希；恢复时规则变更要求重建上下文，执行期间规则变更也会暂停后续工具操作 |
| 旧稿保护 | 新反例可能导致全书自动改名、假名消失、历史引用被覆盖 | 规则更新不改现有正文、候选或已接受名称；仍走候选、差异、批准及版本核对流程 |
| 台账能力声明 | 新文档第十节提出完整命名实体台账，现有事实 ID 不能直接充当实体 ID | 在执行器中明确能力边界，保留原文要求，未声称单次规则更新实现了实体登记、语境改名和别名全生命周期 |

“全题材”在本次更新中指命名规则覆盖范围。原 11 阶段创作流程和其中已明确的创作默认没有因此全部重构；例如原 Skill 的首批公开打脸要求仍保留。需要调整这些创作流程时，应单独修改相应需求，不能把命名升级当作默许改变全部工作流。

## 3. 实际运行方式

1. 从本地完整命名文件读取版本、通用约束、对象类型、东方幻想条件条款、兼容规则、审阅要求与权限边界。
2. 精确匹配项目“题材”字段，允许用 `＋`、逗号或斜线组合。当前客户端的旧默认名“脑洞玄幻”对应 G08“玄幻脑洞”；不会改写作品配置。否定句或无法识别的自然语言不做关键词猜测。
3. 加载相关模块正文和全部 49 个模块的名称索引。例：都市脑洞＋规则怪谈预载 G02、T01；双男主＋东方仙侠预载 G35、G09。
4. 模型遇到另一个世界、特殊对象或尚未读取的题材，调用 `read_naming_rules` 取得相应 G/T 模块。每次可读取 1—8 个，支持多次读取；返回完整模块正文、版本及来源哈希。工具不接受任意文件路径、不访问网络、不读取密钥。
5. 同时按需读取本书人物、世界、术语、知情边界等正式资料。仅凭一个题材标签不能认定医院、天庭、测命体系或人物关系已经存在。
6. 所有生成仍先进入候选；本次更新不增加 AI 自行批准、提前进入下一阶段或改写正式文件的权限。

默认“脑洞玄幻”下，首次命名提示为 24,317 字节，相比整份 43,473 字节减少约 44%；这是 UTF-8 字节比较，不是精确 token 或费用承诺。S01 整个系统提示为 84,287 字节，作品上下文及工具历史另计。新版通用约束比旧版更完整，因此仍比旧短规则占用更多上下文。现有每轮完整请求容量检查继续生效，资料超限会暂停，不会为了塞进窗口静默丢弃硬约束。

第十一节的 12 个文学验收情境保留在原文件中，作为审阅用例；没有把测试故事当作作品设定传入。按需工具读取正确、文本符合命名语义，是两件不同的事，后者仍须模型与作者审阅。

## 4. 本次实现与尚未实现的边界

已实现：新规则接入、模块预载和按需读取、完整版本指纹、损坏规则报错、工具调用留痕，以及对原有候选/正式稿、批准、文件版本和恢复机制的回归验证。

以下要求保留为后续客户端能力，不能算作已经完成：

- 独立的命名实体台账及完整编辑界面，覆盖世界、时代、别名类型、命名规则版本、实体身份等全部字段。
- 根据实体身份和剧情语境，一键区分当前本名、旧身份、假名、历史版本的改名工具。
- 对近义机械拼接、同音形近、制度错用或泄密的可靠自动语义判定。

“新候选不得使用问罪碑、验命石、审判钟”已作为所有阶段的模型规则加载；当前没有加入不分语境的字符串硬拦截器，避免误伤审阅引用和旧稿。不能据此保证任意模型都绝不会输出违规名称；接受候选前仍应核对。规则第十节的候选保护和版本校验由既有代码实施，其他未实现部分已向执行器明确说明，避免它谎称台账已自动更新。
