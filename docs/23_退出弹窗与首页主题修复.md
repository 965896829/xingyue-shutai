# 0.3.3 退出弹窗与首页主题修复

日期：2026-10-09。基于 0.3.2，修复作者截图中的两处主题遗漏。

## 界面变化

- 窗口关闭按钮、菜单退出及应用退出请求统一进入客户端退出弹窗。弹窗使用现有主题变量、品牌符号、圆角、按钮与遮罩；日间白底、夜间蓝灰底。
- 默认聚焦“继续写作”；Esc、右上角取消按钮或“继续写作”均返回写作。焦点限制在弹窗内，取消时恢复原焦点。
- 首页中央复用 `BrandLogo` 双图层：日间星星、夜间月亮，沿用 480ms 淡化、减少动态效果与首次加载规则。Windows 应用图标仍固定使用已确认的第一张图片。
- 渲染进程未就绪或无响应时，保留系统确认框作为异常退出的后备；正常运行使用客户端弹窗。

## 实现与保护

`CloseConfirmation` 为每次退出请求分配唯一 ID；重复关闭复用当前请求，取消使原 ID 失效。只有当前 ID 的确认才能关闭，重复及过期响应不能再次退出。主进程验证 IPC 来源和输入，不信任界面自行修改退出状态。

`ExitConfirmation` 使用原生 HTML dialog 的模态与焦点控制，不重建工作台、编辑器或聊天。取消只撤销退出请求，不向业务内核发出停止指令。确认后沿用既有内核关闭机制。

不修改作品数据库结构、安装身份、密钥目录或作品路径。工作区已有的断流恢复改动保留；其测试补充显式类型和模拟协议字段以通过类型检查，本轮未改动该业务实现。

## 本机验收

- 类型检查、生产构建通过；130 项自动测试通过，包括 3 项退出确认状态测试。
- 全局 Playwright 连接隔离 Electron 实例，实际触发窗口关闭、菜单退出和应用退出请求，三者均进入自定义弹窗。
- 日夜弹窗颜色、首页图片来源、加载状态和最终透明度通过；日间主图透明度为 1、夜间为 0，夜间反向。
- Tab 焦点保持在弹窗；Esc、取消按钮、“继续写作”均可返回。
- 未发送聊天内容和选区保留；编辑器焦点、修改和撤销历史保留。
- 本机模拟模型流式回复期间取消退出，回复继续直至 complete。此项没有调用收费真实模型。
- 过期请求 ID 被主进程拒绝；点击“退出”后隔离进程正常结束。
