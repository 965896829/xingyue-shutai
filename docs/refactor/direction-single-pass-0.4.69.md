# 0.4.69：三个方向改为一次生成

这次只简化“创意 → 三个故事方向”的默认执行链。生成完整三案并通过本地结构检查后，直接供作者选择或提出修改。选定方向后的完整作品方案仍独立检查，书名阶段和原 Skill 的 S01—S11 执行规则保持原样。

## 执行链变化

| 情况 | 0.4.68 | 0.4.69 |
| --- | --- | --- |
| 三案一次生成成功 | 生成 → 独立方向审查，通常 2 次请求 | 生成 → 本地检查 → 查看，1 次请求 |
| 方向审查提出需要修改的问题 | 再修订 → 再审查，共 4 次请求 | 不再执行方向审查、自动语义修订和复查 |
| 作者主动重做一案或换一批 | 生成后再次独立审查 | 每次有效修改只生成一次 |
| 输出缺字段、引用错误或误改冻结方向 | 本地拒绝并定向纠正 | 保留，避免将坏结构交给界面或后续阶段 |
| 选定方向后的完整方案 | 生成作品方案和设定拆解 → 独立检查 | 保留；必要时仍有一次自动局部修订及复查 |

正常三案阶段不再加载审核模型，不再发送审核提示词，也不再等待审核回执。该阶段的内容质量取舍由作者看三案后选择或提出修改；最终选中的完整方案仍接受原有语义检查。

## 保留的内容和保护

未删减三案的输出字段、生成提示词或工具结构。每案仍包含标题、简介、持续剧情机制、差异、开篇决策、首卷变化、长期风险、创意改动说明和标签落实情况；总报告仍含定位、诊断、假设、推荐理由、市场主张和未决问题。

保留输入与报告指纹校验、三个不同方向编号、标签覆盖和假设引用、冻结方向保护、作者必保留项与禁区、重复点击幂等、总调用预算、未知请求结果保护及真实执行记录。没有提高轮数上限，没有改变模型或推理强度，也没有修改用户作品和模型配置。

旧版本停在方向审查或自动方向修订的任务，在明确恢复后验证并展示已经保存的完整三案，不再追加方向请求。旧审查意见保留为折叠的历史参考，不伪造“检查通过”记录，不再阻止选择。上次请求结果未知的记录仍要求明确恢复，未知费用不会被改写为已知。

界面进度变为“生成三个方向 → 查看结果”。耗时记录按新版单次生成单独统计，不混入旧版方向审查循环或旧检查点的本地恢复用时；更换审核模型也不再改变三案阶段的估时分组。
