# 0.4.5 开书体验复查

2026-10-11。按作者要求，从空白客户端点击“新建作品”进行体验检查，并继续修正实际操作中的阻碍。测试从真实新建表单进入，没有预先创建用于通关的作品。

## 发现与调整

0.4.4 虽然合并了阶段确认，但开书入口仍默认展示创建方式、快照版本、主分类和七组标签；创作想法在表单下方，创建后还会重复展开同一套输入。普通阶段的文稿需要再点文件才能阅读，修改意见藏在恢复操作中。重新打开作品还可能先进入讨论页。

0.4.5 默认沿用原有 Skill 的直接设定拆解路径：填写暂定书名、保存位置和一句创作想法，点击“创建并开始”，结果直接出现在任务页。普通阶段满意就“确认并继续”，不满意直接输入修改意见，也能保存后暂不继续。已有输入和确认过的内容自动带入后续阶段，不必重新填写任务。

标签策划作为可选功能放进“更多开书选项”。需要比较三个方向时主动启用；主分类仍由作者选择，额外标签和限制按需填写。方向设定集中显示，修改输入默认折叠。既有标签作品仍继续原有策划流程，不转换旧记录或移除标签能力。

未配置模型时只创建作品，页面提供模型设置入口。已有模型时，按钮与说明明确会开始生成。结果仍需作者确认才正式接受，继续只启动下一阶段，不连续自动采纳。修改意见沿用既有恢复接口；未知请求仍保留重试确认。

重新打开作品会定位未完成任务。暂停在阶段边界时显示下一步及开始按钮。首份阶段文稿默认展开，其余可展开阅读；差异、编辑和检查仍可使用。配色、图标、CSS 与侧栏不变，本次有意调整两个组件的操作分组、默认展开状态及文字，没有新增代码注释。

## 实际操作验证

通过全局 Playwright MCP 控制 Windows 10 Electron 窗口，使用独立配置目录和新建作品：

| 路径 | 实测结果 |
|---|---|
| 未配置模型的新用户 | 创建后保存想法，不发起模型请求；模型设置入口可见；配置后不用重填想法即可开始 |
| 已配置模型的默认开书 | 三项信息填写后，点击“创建并开始”直接生成设定拆解；未进入标签选择 |
| 阅读与修改 | 首份文稿直接可读；输入修改意见后调整同一个未接受任务，没有另开阶段 |
| 确认继续 | 设定拆解确认后自动进入项目与文风；再次确认进入世界规则，各阶段保留单独接受状态 |
| 进程重启 | 在项目与文风待确认时关闭实际客户端，再启动并点击作品，直接回到待处理结果，没有重发生成请求 |
| 暂不继续 | 接受世界规则后停在人物与连续性，未生成下一阶段任务；刷新后仍可一键开始 |
| 可选标签开书 | 新建时启用标签后自动策划；空修改意见可集中确认方向，接受设定后可停在下一阶段 |
| 模型能力不符 | 工具未启用时零轮调用即暂停，作品保留；选可用模型后通过已有交接入口继续，无需重建作品 |
