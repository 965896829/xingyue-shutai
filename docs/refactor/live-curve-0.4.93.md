# 0.4.93 实时叙事线条修复

截图中正文已显示 933 字，但只有一个事件节点。原绘图函数为单节点仅生成 SVG `M` 定位指令，没有可绘制的线段；后续正文增长也不会延长节点曲线，因此画面只剩圆点和进度竖线。

## 修改

- 剧情张力和情绪走向保留原有节点连线，另以虚线将最近一个已知节点的值延续到当前已显示正文的位置。后续节点到达后连接真实节点，延续线从新节点开始。
- 虚线和“节点延续”图例区分延续显示与新判断；不增加事件、评分、模型调用或未生成部分的曲线。情绪缺失时不补零，也不跨缺口延续旧情绪。
- 进度端点落在当前曲线值上，替换原来固定在图表顶端的圆点。线宽为 2.5 像素，缩放时保持清晰；运行时端点轻微闪动，暂停、完成或系统减少动画设置下停止。
- 沿用正文展示使用的同一流式文本，不改正文、模型提示、节点存储、正文哈希或章名规则。
