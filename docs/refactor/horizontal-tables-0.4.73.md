# 0.4.73：生成内容的横向表格阅读

日期：2026-10-27。

## 问题与修改

原文稿预览将表格设置为 `display: block`、11px 字号，却没有为各列分配阅读宽度。中文可以在任意字间换行，13 列总纲因此被压缩成很窄的文字条。不同页面还分别调用 Markdown 渲染，显示行为不统一。

现在任务回答、分段草稿、候选文稿、正式文稿预览、创作讨论、任务对话和完整设定预览共用 [MarkdownContent](../../src/ui/MarkdownContent.tsx)。

- 按表头和实际内容分配列宽。章节、卷数等短编号保持窄列，长描述通常使用 224px，过长字段名称可扩至 280px；表格正文为 14px。
- 宽表格在自身区域横向滚动，不撑大页面。表头固定，适合固定的章节／卷数编号留在左侧；合并单元格表格保留原结构，不强行固定首列。
- 表格有清晰的边界和隔行底色。单元格完整换行，不省略、截断或用摘要替换正文。
- 每份包含表格的内容提供一个“展开阅读”入口。支持 Esc 收起、键盘方向键滚动、焦点返回；流式更新和重新展开时保留阅读位置。普通正文不添加此入口。
- Markdown 管道表格与 HTML 表格共用阅读样式；代码块中的表格示例保持代码。链接、加粗、换行、对齐与合并单元格保持有效，HTML 安全过滤继续生效。

只改变本地渲染。用户作品文件、skill、生成顺序、模型调用、轮数与配置没有改动；已有文稿加载后直接使用新样式，无需重新生成。没有增加依赖。
