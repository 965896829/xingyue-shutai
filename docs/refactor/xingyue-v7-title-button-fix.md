# 0.4.88：作品方案完成后无法生成书名

2026-10-30。0.4.87 新增了“创作与发布”配置投影，但策划范围校验仍只允许旧的契约、项目配置和设定拆解文件。新作品生成完成后因此出现 `tag_planning` 错误，界面同时禁用“满意，生成书名”和手动取名入口。这不是模型未配置或作品方案缺失。

## 修复

- 策划输入包含创作与发布资料时，允许且只允许一份由该输入生成的对应投影。内容改动、重复投影、缺失投影、改写正文和登记事实仍会被拒绝。
- 重开作品时对待审阅的完整方案重新执行本地校验，清除旧版本的误判；不重做方案、不确认作者选择，也不发起模型请求。
- 方案仍有阻断问题时显示“作品方案需要核对”，避免误报已经准备好。

## 验证与交付

- 在用户当前作品的隔离副本中重现原报错；修复后本地确认通过。方案与方向报告指纹、原有 7 轮调用、工具计数和费用记录保持一致，新增模型调用 0。
- 新增暂不发布、男频、女频三种开书回归，覆盖生成方案、确认、命名、采纳、重启清除旧错误和越界写入拒绝。使用确定性模拟模型。
- TypeScript 检查通过；相关回归和安装验证记录位于 `.test-output/title-button-0.4.88`，交付清单为 `output/xingyue-v7/delivery-0.4.88.json`。

0.4.87 的 880 项全量结果保留为历史基线，本次修复的回归范围和数量单独记录，不冒称重新运行了完整套件。未新增付费模型验收调用。
