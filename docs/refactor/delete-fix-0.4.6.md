# 同名作品删除修复 0.4.6

2026-10-11，用户报告删除作品后仍然存在。只读检查确认：回收站中有一部旧《123》，原目录下还有后来新建、身份不同的《123》。原判断只比较目录路径，旧记录会拦住新作品的删除并报“这部作品已在回收站中”。这是真实可复现的缺陷；用户未确认此次看到残留的具体位置，因此不把其他删除失败归因于同一问题。

## 修复

`ProjectRecycleBin.trash` 同时核对路径和作品身份，允许新建的同名作品独立移入回收站。原作品不存在或相同作品已经入站时仍拦截重复删除。目录所有权、写锁、符号链接检查、恢复不覆盖以及七天保留期均继续生效。没有改 UI 或新增代码注释。
