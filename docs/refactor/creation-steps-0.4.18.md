# 开书分步界面与恢复入口（0.4.18）

## 实际改动

开书页分为“选方向 → 确认方案 → 定书名并开书”。每次只展示当前步骤的内容，已完成步骤可回看，未完成步骤不能提前进入。普通创意和标签开书使用同一页面；旧任务依据原有持久化状态恢复位置，旧版两步任务仍可操作。

方向卡保留故事主旨、持续机制与方向差异，开篇、首卷、风险和标签细节按需展开。选择方向后展示该方向的关键假设，明确提示继续即确认，可逐项补充修改意见。“确认方案并生成书名”由一次明确点击顺序完成方案确认与独立命名启动；也可进入下一步手动取名。选择书名与最终采纳仍是作者操作，保存后是否启动 S02 可取消勾选。

普通审核建议保存在原有绑定审核记录中，默认折叠，不再重复转成需要填写豁免理由的提交警告。真正的 blocker/major、确定性校验错误及其他警告继续保持原有阻断或确认规则。旧任务缓存中的重复建议仅在展示时去重，宿主在确认和采纳时仍重新验证版本、内容与审核绑定。

运行状态优先反映失败、暂停及结果未知，不会因为最后保存的子阶段是“整理方案”就一直显示正在生成。当前页提供恢复、暂停、修改输入和完整记录入口；HTTP 502 等错误的原文保留在运行详情。未知结果仍需明确确认可能重复计费后才能重新请求。达到限额或语义修订机会用尽时，指向限额检查或输入修改，不建议无效重试。

## 验证记录

复用 `tests/chat-controls.test.ts`、`tests/tags.test.ts` 及 `tests/fixtures/tag-ui-server.ts`，未增加一次性测试入口。模拟服务通过 `CREATION_UI_SCENARIO` 复现连接失败、费用未知、重要审核冲突和命名失败，入口见 [脚本说明](../../scripts/README.md)。

全局 Playwright 使用真实 Service、SQLite 和隔离作品走查：

- 新建时不要求书名；非推荐方向可选，一般建议折叠。
- 方案请求失败后正确显示停止，点击恢复继续；重启模拟进程后恢复当前步骤。
- 确认方案后启动命名，命名失败不丢失方案批准；恢复后显示三个名字。
- 手填名字经独立核对后可选，仍停留 S01，直到最终采纳。
- 费用未知时取消重试，任务仍为 unknown、调用数仍为 3；明确同意后继续。
- 重要审核问题在页面显示，不提供进入命名或无效重试按钮；修改入口展开并聚焦输入。
- 只保存时进入 S02 且不创建 S02 任务；勾选继续时只创建一个待审阅的 S02 任务，未自动采纳。
- 日夜主题及 1050×780 较窄窗口检查通过，未发现页面横向溢出。
