# 0.4.14：确认方向后确定书名

2026-10-15。修正新建作品仍要求先填暂定书名的问题。

新建只选择保存位置、输入想法，或启用题材标签。客户端先保存未定名作品并完成 S01。作者审阅故事方向后点击“确认方向，确定书名”，确认书名与 S01 产物，再进入 S02；“保存，暂不继续”同样确认书名，但不启动下一阶段任务。
