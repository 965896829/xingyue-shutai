# 0.4.90：风格选择与 AI 推荐

2026-10-30。新建作品与作品设置都增加“创作风格”：清爽快节奏、热血爽感、悬疑紧张、轻松幽默、细腻情感、沉浸写实、鲜活群像，以及可编辑的自定义要求。

## 使用与保存

- 新建作品在选择创作模型后设置风格；所选文本同时进入项目配置与开书策划输入。
- 已有作品通过“作品设置 → 创作风格”修改，保存后更新配置文件中的风格字段。未保存的选择、取消设置和 AI 推荐本身均不修改正式配置或已有正文。
- “AI 推荐风格”使用当前创作模型，结合创作想法、已保存设定、题材、番茄发布分类、目标读者、视角和作者约束，返回三个可选择的候选，说明推荐理由与取舍，并标记优先推荐项。每次请求只调用一次模型，不自动追加格式修复或重试。
- 推荐是基于本书材料的编辑判断，不是实时市场研究或销量保证。风格变更只约束后续表达，不自动重写已完成章节；已启用的详细声音档案仍通过原有文风审阅流程维护。

## 请求与兼容

- 复用请求账本与操作回执，重复请求复用已完成结果；未知结果不自动重发。可停止请求，更换作品、模型或创作输入时废弃旧推荐。
- 推荐期间禁止并发启动创作任务或保存项目设置，避免输入与结果错配。项目会话与版本变化时拒绝旧结果。
- 新建作品尚未打开项目时使用全局请求账本；模型网关为此兼容没有项目的缓存标识。
- 保留原来的默认风格文本与配置结构，不增加必填迁移字段。新增字段只存在于推荐请求与候选返回值中。
