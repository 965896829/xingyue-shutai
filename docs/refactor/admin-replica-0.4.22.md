# 原管理后台复刻与客户端接入 · 0.4.22

## 本次修正

0.4.21 把完整客户端放进 iframe，出现两套侧栏，且没有保留原后台完整页面。本版直接移植 `D:/aiwangzhan/novel-platform/apps/admin/src` 的页面依赖、表单、表格、交互组件和样式。导航依据原 `services/api/app/catalog.py`，保留 8 组、53 个原栏目，增加 6 个客户端专用入口。移除 iframe 及 workspace.html；同一页面只保留原后台一套主导航。

原始文件来源和摘要见 `src/admin/reference/provenance.json`；摘要用于标识移植来源，不是改造后文件的校验值。结构化内容的只读预览字段另取自原 `services/api/app/structured.py` 的 `builtin_config`，不代表客户端生效规则。没有复制原平台的数据库、账号、密钥、订单或环境配置。

用户确认的边界：全部保留原页面，先接通客户端已有功能；其余明确标出尚未接入。原平台的云端引擎、多人账户、收费和发布服务不在本版伪造实现。

## 数据与连接

- 浏览器使用原有一次性链接配对、HttpOnly 会话、CSRF 和本机 Origin 检查；仍只监听 loopback。
- `reference-api.ts` 把原页面请求映射为已有客户端命令，持久化仍由 Electron/worker 执行。网页不直接操作作品数据库。
- API Key 经客户端已有系统加密存储；返回页面只有是否配置，不返回明文。空密钥表示保留，修改地址沿用已有换端点保护。
- 平台保存绑定表单载入时所有模型版本与启用状态；模型/平台删除同样校验版本。网页和桌面并发修改不会静默覆盖。
- 实时事件刷新本机状态及查询缓存。任务通知来自当前作品已载入任务，已读标记只保留在本次浏览器会话。
- 管理日志仅记录操作元数据，不记录密钥、正文、授权链接。任务事件沿用持久化分页接口。
- 原有桌面布局和功能继续使用原 CSS；网页复用组件的 CSS 限定在业务模块内，避免污染原后台样式。
