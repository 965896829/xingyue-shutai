# 0.4.51：身份与数量解析兼容，不以重写内容解决误报

0.4.50 诊断在已采纳角色卡中发现另一种原模板允许的“稳定身份标识C005”写法。为避免继续到章末才触发同类误报，测试在当前 S05 请求返回后主动停止，六次实际 HTTP 请求均完整保存，独立诊断用时16分26.487秒。停止由测试宿主的发送前检查实现，日志中的本地未知状态不代表发出了第七次请求；没有修改运行中的客户端代码或中途重发。

同时保存的 S05 原始分卷表使用 `450000字（45万字）` 等等值注释，旧解析器误判格式和容量。两项兼容问题均使用实际产物回放修复，不编辑测试内容：

- 只从已采纳角色卡的明确身份字段、重要度/当前身份里的身份定义及编号标题读取身份；兼容人物编号、稳定身份标识、实体ID等写法。重复编号不任意匹配，候选新增编号不能授权未出场人物修改。
- “孙亮（正文称持刀男子）”保留明确姓名主体的匹配，不能用姓名子串把无关人物绑定到同一身份；仍要求本轮有效证据及独立语义审查。
- 字数支持括号内同值单位说明，使用精确整数换算验证两边相等。冲突数值、近似值、小数字符数、错误单位与不完整括号仍拒绝，章节连续覆盖与总容量要求不变。
- 已保存的旧任务如果已有完整事实提交及结束回复，恢复时直接进行本地核验并复用同输入的有效审查，不再索要另一遍空结束消息。

继承此前稳定缓存、完整纲要字段复用、增量台账、合并证据来源及网络恢复修复。未改模型、推理强度、总目标、原Skill模板、正文要求或12轮上限。新增修复后的回归、打包与从头验证分别记录在 `output/harness-compat-final-20261023`，所有先前样本均排除在新的独立运行耗时之外。
