# 0.4.71 内容选择与上下文显示

本次在 0.4.70 的流程精简基础上改动界面与用量展示。用户阅读生成内容，满意后继续，不满意直接发送修改意见。质量校验仍由执行器完成，不再把常规复查作为用户的下一步操作。

## 界面变化

| 位置 | 原交互 | 当前交互 |
| --- | --- | --- |
| 普通阶段结果 | 可手动重新检查候选 | 自动检查保留；常规重复检查按钮移除 |
| 阶段聊天输入 | 发送与按意见修改并列 | 统一发送，明确修改要求由现有执行授权处理；提问不启动修改 |
| 阶段结果保存 | 继续与仅保存同时展开 | 主要操作为“满意，继续”；仅保存收进更多操作 |
| 聊天创作菜单 | 先创建任务卡，再点确认开始 | 明确点击生成后直接开始，宿主继续验证范围、版本与重复执行 |
| 消息附属操作 | 每条回答列出资料、规则记录、保存草稿按钮 | 统一收进“⋯”；联网来源与上下文整理状态仍可直接看到 |

没有删除版本冲突保护、未知远端结果确认、权限限制、恢复功能或正式稿的内容采纳。没有修改 skill 文件、阶段顺序、模型配置、质量阈值、轮数上限或产物模板。任务卡仍作为宿主内部的授权及幂等记录，不要求作者理解内部协议。

## 圆环的计算口径

- 位置：普通聊天输入框、阶段任务输入框、方案与书名页面模型选择旁。
- 分母来自当前选中模型配置。共享窗口显示上下文容量；独立输入/输出窗口显示输入容量。手动连接配置会明确标注，不把代理别名猜成某款官方模型。
- 未核实的官方模式容量显示未知，不使用默认值假装精确。
- 网关记录最终实际发送请求的预算，包括已经组装的前缀和工具定义；不取项目累计 token，不用正文字符数代替。
- 返回可用 usage 后以该次服务端 input 为实测值。cachedInput 是输入的子集，不能从上下文占用中扣除。
- 没有实测用量时，显示“≈”与本地估算；区分分词估算、UTF-8 字节保守上界、已测前缀加未测尾部上界。
- 模型、连接版本、窗口或输入预算改变后，不把上一个配置的用量套在新模型上；等待新请求测量。
- 未发送、明确失败、结果未知、服务端未报告 usage 分别保留真实状态。未知不等于零。
- 圆环表示最近一次请求的输入占用，不是累计调用费用，不包含尚未发送的编辑文字，也不声称是服务端隐藏状态的实时精确大小。输出上限与安全余量在详情中独立说明。

本次用量和压缩字段都是可选元数据；旧任务没有这些字段时仍可读取。IPC 契约已生成并验证，不把本地统计重新塞进模型提示词。

## 压缩展示

复用已有本地上下文交接，不增加模型调用：

1. 阶段交接：移出已完成阶段的执行历史，保留当前完整来源、作者要求、未完成草稿及闭合的当前工具链。只在真正建立新检查点时记录一次。
2. 聊天历史：保留最近消息，将较早消息整理成可回查的索引摘录。原始聊天继续保存；摘录不是已采纳事实。没有声称这是语义无损摘要。
3. 显示正在整理和已完成记录；前后大小用 KB 标明为文本字节数，不冒充压缩前后的服务端 token 数。

同时修复新回复抵达后偶尔仍停在旧消息上的滚动问题；主动上翻历史时不强制跳到底部。

## 验证

所有验证均使用离线确定性模型和临时项目，没有调用用户真实模型，没有改动用户作品和模型配置。

- 单元/集成覆盖：实测值与估算、缺失用量、零用量、缓存子集、模型/版本/容量切换、独立输入窗口、网关未知及明确失败状态、IPC 传输、原消息保留、检查点重启后不重复显示。
- Playwright 实际界面：128K 下单次模拟输入 12,345 显示约 10%；切到 512K 立即更新容量且等待新测量，没有请求；新请求同样输入量显示约 2%。
- 一次包含历史整理的聊天只有一次模型调用；压缩记录从真正的聊天整理路径产生。
- 创作菜单直接开始 S01，模拟执行一次调用，无二次任务卡确认。只提问不会额外生成阶段候选；点击满意后保存 S01 并进入 S02。普通结果没有可见的审查/审核/复查按钮。
- 阶段内聊天圆环使用该条聊天的新用量，未误用阶段累计用量。1000×720 窗口详情浮层未溢出。
- 初次专项测试夹具遗漏关闭文件监听，修正为 Service.close() 后复测通过；另修正测试断言的 TypeScript 可选字符串类型。均属于测试夹具，不是模型重试。

完整测试 690 项全部通过，最后的上下文与断流专项 20 项全部通过；8 组真实界面断言通过，最终浏览器控制台无错误。最终打包包含 TypeScript 检查、前后端构建和 NSIS 安装包生成。

完整测试、最终构建日志（`package-release.log`）、截图、请求计数及交付校验在 `output/content-first-context-0.4.71-20261026/`。本次没有实测真实模型生成耗时，不以模拟耗时承诺真实速度、缓存命中率或文学质量提升。保留原有质量检查与输出结构，界面显示不触发额外模型请求。

安装包生成后尚未覆盖安装原客户端。已有作品和模型配置保持原位置。
