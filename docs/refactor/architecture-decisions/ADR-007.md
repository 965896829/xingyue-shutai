# ADR-007 Windows文件竞争

事实：先检查再覆盖存在TOCTOU；Windows文件可能被占用。

决定：原文件先移到确定保留路径，再核对捕获内容；创建新临时文件并无覆盖安装；冲突保留原件。

限制与否决方案：不宣称所有文件系统有原子条件交换；不删除保留文件。

验证：Windows插入竞争、真实占用、hard-kill file边界与hash。

性能复核：私有物化暂存文件和新建备份目录中的文件用独占创建加 fsync，省去没有覆盖目标时的一次 rename；正式路径仍只通过无覆盖链接安装。已有半写暂存文件从校验过的不可变对象重建，原文件保留路径和写后 hash 校验不变。已添加半写暂存恢复用例。

备份每32个文件保存已刷盘文件的 hash 清单并让出事件循环，退出信号在批次边界中止；未完成目录仅有 pending 清单，不能作为完整备份恢复。重试建立新的独立目录，避免把旧源快照和新源快照混用。手动和采纳后自动备份均使用维护资源调度。导入预览仍为原来的30MB有界同步解析，未冒充已实现任意大文档流式导入。
