# ADR-007：Pi 负责执行循环，Skill 与客户端负责创作约束

日期：2026-10-28；版本：0.4.78。替代 ADR-006 中“新任务默认 Legacy、Pi 仅开发实验”的决定，不改变旧记录的恢复身份。

## 原因

0.73.1 的实验桥接缺少阶段、策划、书名、聊天的完整生产接入；完成候选后会多发收尾请求，原生消息、计数、流式显示和检查点也不能只依靠临时 Pi 会话。仅开启旧开关不能解决这些问题。

## 决定

- 固定官方新作用域 `@earendil-works/pi-agent-core` / `pi-ai` 1.4.0。来源提交 `4a080252f06caf63a525d7873c5d94d3c23887e0`，保留 MIT 许可。
- 新任务由 Pi 的 `runAgentLoop` 驱动。阶段、修订、策划、书名及正文分相循环使用同一个 `runTaskLoop` 接口；新聊天也走此接口。旧任务使用 Legacy 调度分支，共享同一套业务回调。
- 原 `ModelGateway` 是请求的唯一出口，原 `ToolGateway` 是工具执行入口。Pi 只看用于调度的临时投影；四协议 native 块、缓存键、费用、原始参数不经投影回写。
- `finishTurn` 在宿主确认完整候选或完整任务提议后结束，不向模型索要额外“完成说明”。Pi 自动重试关闭，原未知结果恢复策略与累计上限不变。
- 已知内部字段名称、可解析的完整 JSON 围栏在本地处理。未知引用、负面审稿结论、内容缺失、版本冲突仍按原规则处理。
- 保留 Skill S01—S11、模板/产物、正文审稿、结构化记忆、作者采纳和真实冲突检查。Pi 不自动跨过作者的内容选择。

## 边界

本次不安装、不修改真实项目和模型设置，不发真实模型请求。Pi 本身不能承诺更好的文学质量、95% 缓存或固定速度倍数；本次仅对可重现的冗余请求及格式阻断做减法。

取消、轮数耗尽、未知网络结果、旧检查点、四协议续轮、重复工具编号、持久化失败和流式增量都有离线覆盖。完整测试与安装包核对的实际结果以本次交付记录为准。
