# 0.4.92 番茄章节命名统一

用户反馈：批量细纲中的“签字之前”等题名过于笼统，需要与书名、卷名采用同一套番茄商业表达标准。

## 实现

- 新建 S08 批量细纲、S09 单章任务、S10 正文及对应创作工具装配版本化章名规则。按具体矛盾、主动选择、信息揭示和阅读回报命名，允许自然短名、转折和角色口吻，不默认四字意象或模糊过渡题名。
- 标题承诺受本章情节与揭示预算限制。申请不能写成获准、输掉对练不能写成碾压获胜；不为标题增加系统、战绩或敌人。
- S09 沿用已确认批次题名，S10 优先沿用已确认单章题名。正文或任务清单另起标题时，本地仅对齐标题；兼容“本章正文”和只有章号的旧首行，不更改正文及章号。
- 对齐发生在正文哈希、质量核对和记忆提取之前，叙事节点按原句重新定位，避免标题长度变化导致曲线节点丢失。断流保留当时收到的草稿和节点，不额外重发请求。
- 作者明确要求换章名时可以覆盖继承名称，继续任务保留这项意图。“只改章名”冻结候选的其他文字、单章细纲及故事记忆，工具提议、恢复核验和正式采纳都检查范围。
- 纯改名且原证据仍可唯一定位时，不把剧情标为待核对；候选本来已有剧情修改或原证据失效时，仍保留相应影响。
- 旧任务没有命名版本时继续沿用原提示与指纹；明确提出章名反馈后才升级。重建任务保留已有候选和累计调用额度。新增命名版本随客户端协议和批准指纹保存。
- 保留原文稿模板，不增加命名解释、营销点评、评分或来源注释。命名在已有生成请求内完成，不增加独立取名、打分或搜索调用。
