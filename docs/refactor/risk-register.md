# 风险与未验证范围

0.4.78 更新：Pi 已改用新作用域 1.4.0 并进入生产执行路径，见[当前准入矩阵](executor-capability-matrix.md)。下表是早期改造的历史风险记录；其中旧包弃用和“生产无 Pi”不再代表当前实现。真实模型性能及覆盖安装本轮均未复测。

| 风险 | 本次处置 | 后续最小动作 |
|---|---|---|
| Pi弃用及开发依赖高危链 | 仅devDependency；生产无Pi；全部准入前不启用 | 在单独升级任务验证新作用域/版本及完整10门槛 |
| 覆盖安装可能改动用户正在使用的客户端和注册表 | 不运行本机覆盖安装；交付独立输出 | 在隔离Windows用户/虚拟机执行0.4.0→0.4.2和功能回退 |
| 实际付费质量/供应商行为未知 | 所有模型验证为本地/合成；无真实费用 | 获得明确端点、数据与费用授权后跑T-066 |
| Windows极端外部竞争、占用、断电 | 原内容先保留、无覆盖安装；进程kill和插入竞争已测 | 多编辑器、SMB/FAT、真实磁盘满与断电矩阵 |
| 提交p50增加约10ms，11轮样本仍有长尾 | 删除私有文件多余rename，保留恢复检查；51对复测p95增加5.5% | 保留原始样本，继续在目标硬件复核，不删持久化换速度 |
| 大型导入和完整UI指标覆盖不足 | 0.4.2在30MB上限内隔离解析线程，25秒截止、退出取消和串行调度已测；完整UI指标仍不足 | 持久化分块DOCX导入检查点、全UI交互延迟矩阵；见[优化证据](optimization-0.4.2.md) |
| 许可与签名 | 锁文件和许可清单；保持未签名 | 发布前审阅所有分发许可并配置签名；自动更新未实现 |
| 历史容量继续增长 | dry-run默认不删，恢复对象永不自动移除 | 后续实现细粒度pin和删除中断回收测试 |
| 提示注入完整攻击语料不充分 | 字段来源分类，模型无正式批准/任意网络/终端能力 | 扩大攻击语料和四协议原生续轮矩阵 |
| 全部硬件/损坏场景无法用注入替代 | 区分逻辑故障注入与真实设备故障 | 逐环境发布前验收，不写通用发布就绪 |

本轮架构和隔离测试可交付；Pi正式准入、真实付费模型、Windows覆盖安装仍是明确缺口。没有将条件未满足的项目计入通过。
