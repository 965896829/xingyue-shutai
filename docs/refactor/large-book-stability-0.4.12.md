# 0.4.12 大书稳定性实施与验收

2026-10-12。300 万字只是新书配置默认值，不作为存储上限。此次以 5000 万正文字符、20000 章、20000 条有原文证据的事实进行实际落盘验收，不把配置允许填写 5000 万等同于已经验证容量。

## 实施内容

- 原文使用持久化中文分词及单字、双字索引，支持两字姓名。先按作品快照、章号和待核对状态限定正式版本，再检索、排序和去重。短查询优先匹配完整原句，缺失索引时逐篇回退读取；旧书后台补建索引，可随关闭作品中止。
- 当前版本与历史版本分别以文件路径、内容哈希匹配。入选片段再核对原文对象；检索缓存内容异常时修复缓存并停止本次返回，不把错误缓存当作证据。
- 上下文编排只直接检查本次必读资料、有效事实来源和入选原文。原文变化仍使资料包失效，硬约束超预算仍阻断请求，不通过减少约束换取容量。
- 快照保存文件、章节状态和事实的增量，每 128 个快照保留完整检查点；读取端还原完整历史，保留事实顺序、删除记录和版本链校验。300 版回归用例逐版还原一致，存储文本不足全量方案的十分之一。
- 已完成的提交日志不再重复保存全作品状态和完整任务；未完成日志保留恢复载荷。读取恢复日志、对象引用和待恢复聊天改为逐条处理。
- 可选语义检索逐批读取向量，只保留有限个排名结果，并检查正式版本与原文。十万条合成向量的排名回归通过；本轮没有连接外部 Embedding 服务。
- 目录扫描复用排序器和数据库目录映射，减少重复路径检查；界面快照复用目录状态，保存、外部变化通知和定期校验使缓存失效。主动扫描仍重新检查磁盘，生成前的证据检查直接访问相应文件。
- 长文件列表只渲染可见区域，保留现有按钮、样式、搜索、鼠标和键盘操作。禁止浏览器滚动锚点干扰虚拟列表定位，Home/End 和首尾文件可正常访问。未增加源码注释，未改总控 agent.md 内容。

## 真实容量测试

环境为本机 Windows 10 build 19045、约 32 GiB 物理内存、Node 24.11.1；测量进程设置 1024 MiB JavaScript old-space 上限。输入为可重复生成的中文合成正文，每章按客户端计数 2500 字符，总计 50000000；不同章节包含唯一线索与有据可查的状态，语句仍有重复，不能等同于五千万字真实小说的全部复杂性。

| 操作 | 测量结果 |
| --- | ---: |
| 正文写入 | 20000 章，约 661 秒 |
| 核心服务打开、校验与目录读取 | 61.646 秒；首轮优化前 114.976 秒 |
| 30 次精确线索检索 | 中位数 793 毫秒，P95 917 毫秒，最大 1245 毫秒 |
| 当前章资料包 | 2.960 秒，54572 字节，保留最后一章伤势硬约束 |
| 保存一次前文修订 | 3.507 秒 |
| 提交中断恢复 | 通过；恢复后的正文与预期一致 |
| 保存前历史原文 | 通过；与保存前字节内容一致 |
| 测量进程 RSS 峰值 | 751 MiB，不含 Electron 窗口及其他进程 |
| 连续检索的回收后堆内存 | 第 5 至第 30 次均约 136 MiB |
| 数据集历史快照 | 207 个，存储 JSON 共 15184039 字符 |

完整数据通过生产 FileStore 提交与 Service 打开，不以直接伪造数据库代替存储路径。正文按每批 100 章导入，事实最终集中登记；这不是连续执行 20000 次模型写作的测试。首次测试的事实夹具使用了非法类别，被类型校验拒绝；修正为合法时间线事实后续写，未重复写入正文。

隔离的实际 Electron 窗口由全局 Playwright MCP 操作：目录含 20026 个文档，顶部实际渲染 25 行，目录筛选约 53 毫秒；End 定位最后的阶段索引，Home 返回第一项；打开第 11000 章并完成界面刷新约 3244 毫秒，正文内容正确。另已打开第 20000 章并核对伤势原文。窗口截图见 `output/playwright/large-book-0412/chapter-11000.png`。

全套 262 项回归通过；目录缓存和最终路径校验改动后补跑 53 项相关回归全部通过。类型检查、生产构建和 NSIS 打包通过。回归包括独立进程强制中断、SQLite 升级中断、文件占用、旧版本读取、证据失效、预算阻断和目录联接拒绝。

## 可复现记录

- `npm run test:large-book`：先构造再测量，默认 20000 章；支持 `-- --output=.test-output/新的隔离目录`，不请求远端模型。已有夹具会从进度记录续写。
- `tests/large-book.ts`：写入、打开、检索、编排、保存、历史与恢复测量。
- `tests/large-book.test.ts`：增量快照、短中文检索、版本隔离、缓存修复、索引中止、日志恢复、向量排名、目录缓存及路径安全回归。
- `.test-output/scale-50m-20261012/final-report.json`：最新完整核心测量和内存记录；原始多轮记录在同目录 `large-book-report.json`。
- 同目录 `final-full-tests.log`、`cache-tests.log`、`ui-report.json`：回归和窗口操作记录。
- `tests/profile-large-book.ts` 与同目录 `profile*.log`：定位完整性校验、事实重建和目录读取的耗时。

## 边界与后续工作

首次打开仍需全量历史对象完整性校验、证据检查和目录枚举，五千万字测试约一分钟，尚不能称为秒开。定期目录校验仍随文件数量增长，在较慢磁盘上可能延迟同一工作进程的读取操作。下一步优先把完整性检查和目录核对做成可中止的分批任务，并为大量事实引入数据库级条件查询与分页，不能直接取消证据检查。

测试没有覆盖五千万字单文件编辑或一次导入；当前单个导入文件仍有 30 MiB 限制。大书应按章节保存。未进行低内存机器、磁盘满、电源故障、数月持续运行、百万事实、全部长期存续硬约束以及真实模型全书连写测试。合成容量、上下文有效性和模型长篇叙事质量是不同的验收项；没有承诺无限规模或完美稳定。
