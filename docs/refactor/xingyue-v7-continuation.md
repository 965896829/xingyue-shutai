## 共创画布

- 写作工作台新增中央画布，人物、关系、剧情和世界共用章节、正式版本和作者／读者／人物视角。数据来自已有正式文件与事实投影；历史版本只读，人物与读者视角不使用整份作者档案补空白。
- 对象和字段使用稳定身份，保留来源版本与 Unicode 位置。旧 Markdown 按角色段落或表格单元格定位；重复文字不能导致修改另一人物，插入其他字段不会改变已有字段身份。
- 单字段修改先生成现有任务系统的候选，作者采纳前不改正式资料。固定某字段后，存储提交入口也校验锁，其他入口不能绕过；其余字段仍可修改。
- 对象讨论绑定作品、对象、范围和版本，包含当前字段、固定内容及来源。打开讨论、切换范围和绘制关系图均不请求模型。讨论生成的修改只能指向该对象的来源文件，不能启动整个阶段任务。
- 关系图保留方向，只画所选人物的一跳关系，最多 12 条；超过上限会明确显示数量。图节点支持键盘操作。未来计划与确认资料分开呈现，缺失值不会用模型填充。
- 宽屏并排显示画布和讨论；窄屏改为纵向滚动。修正了展开讨论后挤压画布、无障碍提示产生页面空白，以及从画布打开文稿时编辑器被隐藏的问题。首屏隐藏内部身份编号，操作集中在来源、修改和固定。
- 连续缩放窗口曾复现输入框的 `ResizeObserver` 循环警告。高度调整改为下一动画帧执行并在卸载时取消；同样六次宽度切换后未再出现未捕获错误，20 行输入与清空后的高度伸缩也通过检查。

实现入口：`src/ui/ObjectWorkbench.tsx`、`src/core/workbench.ts`、`src/core/workbench-documents.ts`、`src/core/workbench-locks.ts`。锁和界面偏好不构成第二套故事事实库。

## 离线匿名试读

- 客户端可导出所有对比试读为一个独立 HTML，支持每场景 2—6 份样稿。公开文件不含实验族、模型、运行记录或候选内部身份；匿名顺序按参与者在本机固定。
- 反馈 JSON 保留实际展示顺序、正文 hash、偏好／平局／都不满意／弃权、理由、后续问题、阅读感受，以及 Unicode 原文标记。
- 客户端导入时一次性核对所属作品、试读包、展示版本、顺序、时间和原文范围。任何错误都不会部分保存；重复导入或仅更新时间后再次导出不增加计数，已撤回内容不会被同内容重新导入恢复。
- 反馈详情可查看原文标记和后续问题，并撤回记录。作者、目标读者、模型模拟分别统计；读者来源是提交者声明，不等同于身份已经验证。
- 旧质量实验已登记同一试读包，更新后的交付页面仍为 31 组，包身份保持 `bdfe118fc2de9250e407e5b39028d9deedc213b5215116d5f144623dbfca5624`。私有对应表仍保存在测试证据目录，不进入公开 HTML。

实现入口：`src/core/blind-review.ts`、`src/shared/review-page.ts`、`src/ui/QualityWorkbench.tsx`、`src/ui/ReviewObservations.tsx`。质量状态增加的包、收据和标记字段均为向后兼容的可默认字段；原始导入数据留存以便核对。
