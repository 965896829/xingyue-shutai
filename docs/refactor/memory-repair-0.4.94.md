# 0.4.94 章后更新修复

正文生成后，缺失人物覆盖或覆盖与事实不一致会原子拒绝章后提案。此前该失败分支没有保留可复用的文件提案；随后模型读取资料准备修复时，客户端又把成功的读取回执当成新的完成提交，提前消耗自动修复次数。

## 修改

- 人物覆盖校验失败时，保留已通过文件权限和版本检查的提案回执。修正事实与覆盖后可以复用文件提案，全部检查仍会重新执行，正式作品不自动改变。
- 覆盖格式错误仅在章节记忆处理器中延后至文件检查之后验证；其他工具和参数仍在入口拒绝。无效覆盖不能写入候选或绕过独立审阅。
- 只有成功的文件或记忆提交才触发阶段完成检查；读取资料和本地检查不消耗额外修复次数。
- 缺失章后报告只提示尚未生成，不再同时报告“字数未知”。报告存在但计数错误时仍要求更正。
- 运行中隐藏尚待生成的人物行为记录提示；暂停后保留缺失提示。正文、事实、审核、作者采纳和总预算约束保持原有规则。
