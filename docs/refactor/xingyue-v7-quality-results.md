# V7 真实模型质量观察

## 调用与实验口径

使用用户当前默认配置：`gpt-6.1-sol`，Responses 协议，输出上限 8192。共派发 **100 次**，达到授权上限后停止。供应方返回 100 份完整响应，但完整响应不等于 schema、记忆或文学验收通过。

账本累计输入 127,116 token、输出 64,181 token、缓存输入 23,040 token、推理输出 5,974 token；这些数值沿用供应方字段，不重复扣减或推算价格。实际金额未提供，记录为未知。单请求耗时中位数 25.4 秒，累计请求时间约 45.7 分钟。请求、输出、资源、上下文和模型配置绑定保存在隔离评测作品及账本；没有公开密钥。

`evaluation-report.json` 保存 93 条执行观察，含恢复过程；这些观察并非 93 个独立实验，更不能将失败后恢复当作新的独立样本。

## 已取得的证据

| 测试 | 实际观察 | 解释边界 |
| --- | --- | --- |
| 30 个开发场景 × 两版 | 59 份结构有效；场景 23 的 A 版缺 `assumptions`，按合同拒收 | 29 组可供匿名比较；生成后登记，不冒充预登记实验 |
| 两组独立保留场景 | 生成前登记故事族、变量、约束、问题、预算及停止规则；四份响应有效 | 一组长度 631/312 超出 250–400 目标，单列为长度敏感组 |
| 连续五章 | 五次续写及一次前缀首读完成，前一章作为后章明确材料 | 合成的 500–800 字短章；不是五章完整生产流水线或真人质量结论 |
| 真实旧章核心采纳 | 同一正文 hash 绑定覆盖、核心事实及独立审阅，并提交正式快照 | 只证明被测章节的核心闭环，不能外推所有人物或长期因果 |
| 声音学习与试写 | 场景证据能形成受限候选；纠正日期及未知原因删除返回“证据不足” | 不把合成编辑说成真实作者审美 |
| 角色试演与承接 | 角色保留误信，不获知乙取走钥匙的作者真值；上一回合仅传对白和行动 | 全请求过滤有本地断言；语义边界仍需样本评阅 |
| 解法比较 | 换名换景仍识别“受轻视—隐瞒资格—亮凭证—对手让步”的同构，并引用两场原文 | 不给原创概率，不自动改稿 |
| 有意回响 | “你走前面”在权力与照护关系改变后被标为 echo，保留其叙事作用 | 模型意见供作者判断，不升级为自动门禁 |
| 初读悬念与缺口 | 分开描述钥匙悬念及甲突然改主意的理解缺口，保留不确定性 | 没有宣称真实读者必然流失 |
| 互斥分支 | 只写兼容的夜雨与工具箱片段，知情状态及路线单列待选 | 没有强行补获知事件或写入正史 |

## 实测暴露的问题与处理

1. **人物覆盖坐标错误。**保留错误回执；宿主只对同版、唯一连续引文修正 Unicode 坐标。重复引文或错误正文版本仍拒绝。
2. **记忆文档格式不合法。**真实模型使用“未记录”作为关系极性、用“待采纳”作为伏笔状态。修复提示现在明确叙事状态枚举，不凭空添加未知关系行；修复计入预算。
3. **人物遗漏。**独立审核发现正文中的未具名值守人员未被覆盖，阻止采纳。定向修复冻结正文及未被否定的事实，补齐覆盖后重新审核。最终提交证明的正文 hash 与覆盖 hash 同为 `07b7d8e4687d85376cb9fa3be87ab1421106fa2d6541546a2bb802d094368444`。
4. **未知对话者被误指为丙。**初次角色样例将信念里的丙当作现场催促者。输出规则增加“被提及不等于在场，观察未确认身份就保持未知”。最后两次复验分别询问“你知道丙在哪儿吗？”并保留对方身份和威胁用意未知，没有再给来人安名。旧错误文本保留。
5. **样稿长度超限。**一份保留样稿 631 字，对照 312 字。没有裁剪、删除或重新生成；固定长度分析应使用其余 30 组，超限组独立报告。

执行脚本曾因夹具的目标 hash、默认字数范围或把人物当前目标误记为作者约束而停止；这些属于评测夹具问题，日志保留，未将未发送请求计作真实调用，也未通过放宽角色过滤来绕过失败。

## 与 V6 案例的对应

Q24、Q26–Q32、Q34 有对应的真实输入和输出记录，逐项核读上述行为；其中 Q27/Q29 的首次身份错误与修复后结果分别保留。Q25 使用受限声音试写适配器验证专业资料边界，未把它描述为整章写作流水线已通过。Q33 的阅读推进在当前实现中从正式事件、计划与独立首读结果派生，无额外模型提取回合；计划/正文/模型模拟/真人反馈的分离由本地投影和 UI 验证，未宣称执行了原案例指定的独立模型输出 oracle。

Q35–Q40 的真人盲评仍待实际作者和目标读者完成。作者、读者、模型、演示数据不可混算。现有样本不足以给出文学优胜率、稳定改进幅度、置信区间或平台留存结论。

## 匿名评阅

打开 `output/xingyue-v7/anonymous-review.html`，填写读者代号后开始。每人顺序单独随机并保存在本机；只展示样稿 A/B，不展示模型、提示词或来源。可以平局、都不满意或跳过。可标记连续原文并保存 Unicode 坐标，最后导出 JSON。

隐藏映射只在 `.test-output/xingyue-v7/live-quality/blind-private-mapping.json`；不发给盲评参与者。界面测试导出的 `anonymous-demo-feedback*.json` 是演示记录，真人数仍为 0。生成与导出脚本支持复核，不需要继续付费调用。
