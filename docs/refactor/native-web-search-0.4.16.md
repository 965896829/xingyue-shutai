# 0.4.16：OpenAI 原生联网搜索

2026-10-16。将原生 `web_search` 接入现有 Responses 执行器，使用当前模型连接和 Key；保留作者的联网开关、来源记录、事务保存和未知请求恢复流程。

## 使用方式与范围

在“智能体与联网设置 → 联网搜索”选择“OpenAI 原生搜索”，保存设置。默认“自动”模式也会为支持工具调用的 Responses 模型选择原生搜索。无需填写第三方搜索 Key；“测试已保存的连接”使用所选模型实际执行搜索，并要求返回完成记录和来源才报告成功。

聊天输入框旁的“按需联网”决定当前聊天是否允许搜索，全局开关同时生效。自由讨论、任务内讨论和市场研究任务可用；S01—S11 的普通阶段任务不因此自动获得联网权限。非 Responses 模型在自动模式下继续使用已有第三方搜索服务；选择 OpenAI 专用模式后，不会静默改用第三方。

## 执行与保存

- 请求以 `tools: [{ type: "web_search" }]` 接入，与现有自定义函数工具共存；附带完整来源列表的返回要求，保持 `store: false` 和加密推理续轮数据。
- 流式搜索状态、完整搜索动作、来源及文字引用保存到任务或聊天记录。网页只作为外部证据，不能直接变为正式设定或作品记忆。
- 引用显示为可点击链接，资料面板保留完整来源；重开作品仍可回查。原始响应块保持原样，后续函数工具调用可继续携带原生搜索与推理状态。
- 中断、取消和错误仍记录未知请求及未知费用，不自动重发或切换服务。已有片段和收到的来源继续保留。

## 中转兼容与费用

首次真实联调使用完整参数时，上游返回 HTTP 400。本机中转日志明确给出 `Unsupported parameter: max_tool_calls`，因此不能据此认定模型不支持搜索。修正兼容请求后，同一模型连接完成原生搜索。

“原生搜索兼容性”默认自动：官方 `api.openai.com` 发送服务端次数上限，其他端点采用兼容请求。也可以明确选择完整参数或兼容方式。兼容方式不发送 `max_tool_calls`，次数仅作为客户端参考限制；超出时停止接收并保留记录，上游可能继续执行，不能保证精确的服务端次数或费用。搜索调用和普通工具均计入本地记录，后续请求不会重新获得已使用的额度。

原生搜索包含额外工具费用。当前仅取得 token 用量而无法完整核算工具费用时，费用记录为未知；项目启用严格费用上限时，客户端在发送前阻断原生搜索，不把 token 估算当成完整账单。
