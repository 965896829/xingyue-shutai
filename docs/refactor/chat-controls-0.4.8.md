## 查明的问题与修改

真实《321》任务只读记录和窗口均显示“任务规则或工具契约发生变化，请重新组装上下文”。原恢复按钮继续使用旧规则绑定，模型调用前就再次暂停，表现为点击后没有继续。现在恢复会检查规则、资料及模型版本；普通任务沿用原任务，失效上下文会创建后续任务，保留旧记录、未接受候选和对话，不自动接受结果或跳过阶段。该路径同样用于确认聊天修复方案。

同时修复或补齐：

- 任务与讨论输入框 Enter 发送、Shift+Enter 换行，保留 Ctrl+Enter；输入法组合状态、229 键码和长按不会误发。删除两个输入框的占位提示。
- 换模型继续会带入输入框中的修改意见；空历史任务收到补充要求时仍会组装完整初始上下文。
- 成功恢复清除旧错误，旧回复与新回复之间保留段落分隔。失败任务可再次恢复；异常不会因为失败状态转换再次丢失错误。
- 执行中禁用会冲突的恢复、接受和放弃操作，空作者回答不能提交，缺少模型时给出明确提示；本地操作失败在任务附近展示。
- 问题索引和回复内链接可定位到具体检查项、候选、历史对话错误或恢复操作。候选或问题位于折叠区时自动展开，并聚焦到对应位置。
- 调用次数、工具次数或预算上限可直接打开并聚焦对应设置；模型配置问题可打开模型设置。旧问题已改变或解决时提示状态并返回当前任务，不跳到另一条问题。
- 本地定位链接不再被当成外部网页打开；任务对话中的阅读链接及较早消息加载不受模型执行锁阻拦。普通聊天也支持当前已加载消息的本地锚点。

没有新增源码注释，没有修改样式表、依赖或 Skill 资源。任务限制与未知费用确认继续生效，不会因为重复点击恢复自动提高上限。
