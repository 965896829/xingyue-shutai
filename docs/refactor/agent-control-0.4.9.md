## 总控实际如何生效

此前 `resources/skill/runtime/agent.md` 仅作为方案资源存在，没有进入生产模型调用。现在策划、普通阶段、正文、审稿、记忆提取、讨论、试写和叙事评估都加载同一份总控规则，并保留各自的输出格式与工具边界。模型连接测试、嵌入检索和图像接口不属于创作推理调用，不套用正文总控提示。

规则分工为：程序执行工具权限、预算、版本、审批和正式提交；agent.md 统一规定行为、任务边界、交流方式和创作原则；专项技能与参考细则提供方法和模板。Markdown 不能凭文字新增代码能力，也不能解除程序限制。当前执行器仍是已有的 Legacy 执行器，实验性 Pi 未启用；没有将本次接入宣称为完成通用代理内核重构。

源文件为 `resources/skill/runtime/agent.md`，安装后的生效文件为 `D:/aiwenxu/wenxu-desktop/resources/skill/runtime/agent.md`。它不是外部编码工具的 AGENTS.md。本机作者可直接编辑 UTF-8 内容；每次任务读取实际内容并记录哈希。空文件、包含空字节或超过 96 KB 的文件会阻止调用。其他内置资源继续执行资源锁校验。

执行中检查总控版本，规则改变后暂停后续请求和工具；接受旧结果也核对总控版本。继续旧任务时重新加载规则并保留历史、内容和用量。升级安装仍可能更新内置资源，修改规则后应保留自己的副本；此次安装前完整备份旧规则和程序。

## 修复

- 宿主提供真实的项目、阶段、章号、版本、已接受阶段、授权模式、来源索引和规则版本。同步共享契约，26 个技能登记实际工具名，工具网关按登记限制调用。删除 S02 要求模型另行生成 sidecar 的过时约定。
- 普通阶段缺失或不合格产物在当前范围内自动修复，最多两轮。审稿与记忆阶段同样检查，缺少审稿文件不能跳到记忆或接受。自动修复受原轮数、工具数、预算和文件修改次数限制；未知远端结果不自动重发。
- 重建任务共享根任务请求账本，继承已消耗费用、轮数、工具次数、修复次数及文件修改次数。切换模型不能清零，也不会重复计入既有费用。已有完整正文的交接从审稿重新开始，原正文保留；未完成正文作为后续写作的已有内容提供。
- 每次保存运行记录均递增状态版本，拒绝同状态的过期副本。用量独立追加到持久账本并在读取时合并，后台评估不能覆盖前台内容；停止动作使用正在执行的同一记录对象，避免新版本校验引发假冲突。
- 常驻总控为 5555 字节；详细领域规则保留在 `references/agent-guidance.md` 并按技能选择章节。默认规划阶段的表达规则从 192 条调整为 48 条语言规则，作者显式选择的模块继续加载；正文仍保留 192 条默认规则，905 条原始规则资源完整。
- 只在 Markdown 阅读预览中隐藏 `wenxu-config` 机器配置块，普通 JSON 和作者备注保留，原文件、编辑和差异视图不变。多轮模型回复之间保留段落分隔。
