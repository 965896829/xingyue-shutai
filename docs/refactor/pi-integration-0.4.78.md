# 0.4.78：Pi 接入与请求精简

2026-10-28 完成源码修改、完整测试和 Windows x64 安装包。没有安装到用户正在使用的客户端，没有调用真实模型，没有改动用户项目或模型配置。

## 变更

- 新任务与新聊天由 Pi 1.4.0 的执行循环调度。阶段、策划、书名、正文子阶段和修订共用同一套宿主回调；原模型与工具网关继续负责真实调用与持久化。
- 完整候选本地结束；聊天提交完整任务提议后省去纯收尾请求。Pi 自动重试关闭，累计轮数和未知请求恢复策略保留。
- 已知内部字段、引用编号转换为中文说明；完整 JSON 围栏本地解析。未知引用、截断输出、负面审稿结论、真实内容错误和版本冲突不被当成格式问题放行。
- 保留 Skill 的 S01—S11、产物路径与字段、表达规则、独立正文审稿、记忆提取与证据审核。旧任务按原执行器继续，不清空预算、不替换模型、不丢弃候选。
- 更新现有 DOMPurify、Undici、Zod 的补丁版本，补齐新增依赖许可证。未使用的 Pi 模型传输及遥测代码未进入工作进程；安装包没有重复携带 node_modules。
