# 0.4.15：故事变化驱动后续计划

2026-10-16。目标是让逐章创作形成“正式事实变化 → 后续计划核对 → 作者确认 → 继续下一章”的闭环。保留现有 11 阶段、候选审阅、SQLite 事务、中文目录和历史快照。本轮不修改用户作品、不请求真实模型、不执行覆盖安装。

## 实际修复

此前正常接受 S11 或正文与记忆联合结果不会标记后续计划；只有手动修订才进入粗粒度影响检查。“作品记忆 → 后续计划”的命令又被归入研究任务，无法正式修改大纲。本版补上这两个入口。

- 正常章后采纳后，比较已确认的结构化状态，记录人物、谓词、旧值、新值、生效范围及正文证据。重复提取相同状态不会作为新变化。仅候选状态不生效。
- 从下一未写章节开始核对已有未来计划，排除已完成章节的独立设计文件与未填写模板。已有正文保持正式状态；正文不因正常剧情发展被整批标记失效。
- `dependencies` 同时登记规划文件、正文、相关事实及来源版本。已有依赖链、人物提及和缺失依赖分别给出核对原因。缺少证据的旧资料保守列入，不能据此判为无需调整。
- “调整后续”创建正式修订任务，可指定生效章节。正文和章后记录禁止写入，已识别的过往章节标题段落与表格行不可改动，未来要求只能作为计划或作者约定。故事修订与记忆提取纠正仍有独立入口，纠正提取不能改正文以迎合记忆。
- 修订任务保存来源版本和作者授权范围，带入已确认的定位、世界规则、文风、配置与标签契约。变更依据只读，不能通过改回新状态来迁就旧计划。同步按大纲、章节总纲、批次节奏、批量细纲、单章设计的层次处理；每次调用获得本次已经生成的上游计划候选，独立审核也检查上游一致性。
- “确认并继续”发现待核对项会先进入同步。同步结果提供“采纳同步并继续创作”和“保存，暂不继续”，正式采纳后清理相应影响并保留原写作位置。

## 数据与恢复

`ProjectState.storyImpacts` 保存待闭环的变更来源、范围、状态差异与目标；闭环后从待办中移除，历史快照和改动影响记录仍保留。`Run.continuity` 与 `memoryRepair` 保存授权范围、来源哈希和处理游标，纳入采纳指纹和独立审核指纹。原作品缺少新增字段时沿用原有核对逻辑，无需导出或重建作品。

外部修改来源、修改待采纳候选或切换正式版本会使旧审核无效；任务中断保留已生成候选，不写入正式文件。重启、换模型和备份恢复保留范围与进度。正式文件、记忆、项目状态和影响闭环经同一提交保存，重复采纳不重复提交。

数据库版本升至 6。首次打开旧作品沿用现有升级前完整备份流程；旧客户端会拒绝写入新版数据库，避免把“仅调整后续”的任务误作不受限制的修订。需要回退时使用升级前备份。标签契约作为只读来源进入关联修订和独立审核，并绑定正式版本。

## 维护与验收

在维护中的 `tests/memory-safety.test.ts` 扩展回归，复用 `tests/fixtures/tag-ui-server.ts` 的真实 Service 与模拟模型；没有新增一次性测试脚本。专项覆盖：

1. 同状态重复提取不触发变化；章后正式变化自动核对未来计划。
2. 已写正文与过往计划保护、下一章生成前的阻断。
3. 大纲候选传给细纲、来源正文证据随同步任务保留。
4. 修正入口创建真实修订、候选变更导致旧审核失效。
5. 正式采纳前不覆盖、一次提交闭环及重复采纳。
6. 来源外改、断流结果未知、重启、切换模型与备份恢复。

最终全量回归 277/277 通过，类型检查与生产构建通过。安装包内的四个 Electron 入口及前端产物与本次构建逐字节一致；交付检查通过，包含 26 个注册技能、905 条表达规则与 482 个标签选项。安装包已生成，本轮未执行覆盖安装。

全局 Playwright 在隔离模拟作品走通影响展示、核对按钮、多文件候选、保存后清除待核对项、修正类型及生效章节限制；“采纳同步并继续创作”成功接续第 3 章 S09，保留前两章。浏览器无控制台错误。界面证据位于 `output/playwright/continuity-0415-*.png`；测试、构建、界面快照和交付检查证据位于 `.test-output/continuity-20261016/`。

## 边界

本版实现可追溯的联动审阅流程，并不保证自动找出所有剧情因果。影响候选范围仍包含保守兜底；计划中没有明确章号的混合段落，其时间语义还需要模型与作者审阅。实际修改取决于模型判断，必须由作者采纳。

章后自动触发依赖正式结构化记录；没有被登记的隐含剧情变化不能仅靠文本状态表自动发现。每次同步仍遵守任务次数、费用及上下文预算，不能在预算不足时静默省略硬约束继续。真实模型的剧情合理性和文学质量尚未在本轮验收。

0.4.15 同时包含此前 0.4.14 的“方向确认后取书名”改动。本机安装版最后核对仍为 0.4.13，安装包与安装状态须分开看待。
