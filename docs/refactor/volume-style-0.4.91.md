# 0.4.91 番茄分卷命名统一

用户反馈：分卷大纲采用“擂台另一边”“你的名字在这里”“请把条件写全”等模糊题名，需要与方案中的番茄商业书名标准一致。

## 实现

- 新建 S05 与“全书规划 / 分卷设计”使用分卷命名 v2：题材辨识、具体看点、阅读期待、顺口自然、事实兑现。书名承诺全书，卷名承诺本卷；不默认优先留白、短名或角色对白。
- 容量表和分卷标题一同命名，允许自然的长卖点、转折和两段式，避免整组换词套句。仍使用原模板，不向大纲增加命名解释、来源注释或自评栏目。
- 不增加独立命名模型、评分模型或审核轮次。S05 沿用有界目录研究；分卷设计不额外发起目录研究。已有来源与调用预算在重建任务时保留。
- 旧任务不自动切换规则。无版本与 v1 的专项提示、引用和指纹保持不变；作者明确反馈卷名时，新上下文使用 v2，保留原候选、检索与累计额度。
- “只改卷名”冻结原候选，允许更换容量表卷名单元格与对应标题；工具提交、恢复校验与正式保存均检查范围，禁止同步改剧情、章节容量、其他文稿或故事记忆。
- 保存时区分作者候选与宿主进度、索引、证据位置投影。相对正式稿只有卷名变化且原证据仍可唯一定位时，不把整本书标为剧情待核对；证据引文受影响、或旧候选本来就含剧情改动时，仍按实际影响处理。
- 修复分卷设计任务重建时丢失操作绑定与阶段的问题，保证后续阶段修改已确认分卷时仍受原范围约束。
