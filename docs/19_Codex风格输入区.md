# 0.2.1 聊天输入区改版

日期：2026-10-08。

本次按作者要求，将“创作讨论”底部输入区的视觉排布向 Codex 对齐。参考本机 Codex 的输入区样式特征，使用文序自己的 React / CSS 实现。

## 使用方式

| 位置 | 操作 |
| --- | --- |
| 输入区域 | 随文字增高，回车换行，Ctrl + Enter 发送；中文输入法组词期间不会误发 |
| 左下「＋」 | 提出当前阶段任务、自由试写或正式修订任务卡；选择本轮引用的其他聊天 |
| 模型名称 | 打开模型菜单，搜索模型或供应商；勾选标识当前使用的模型，每次任务仍使用一个模型 |
| 地球按钮 | 开关本聊天的按需联网；窄窗口收起文字，保留图标、状态点和提示 |
| 右下圆形按钮 | 发送消息；正在回复时变为停止；空消息不能发送 |
| 引用标签 | 显示明确选择的其他聊天，点击即可取消引用 |

弹出菜单支持 Esc 关闭并返回触发按钮，点击外部关闭；模型搜索支持上下方向键和 Enter 选择。菜单通过独立浮层显示，打开文稿面板时不会被聊天区裁切。

创作工具只提出确认卡，实际执行仍需作者确认。普通发送仍属于讨论，不套阶段模板、不推进阶段。此版本没有增加附件上传、语音输入、推理强度参数或新的模型协议。
