## 如何理解“功能一致甚至更好”

一致：原 Skill 的输入、产物、阶段依赖、文风、命名、章节设计、记忆、修订影响与校验要求都有实现和验收；不能只做一个聊天框，把所有规则放进系统提示词。

更好：先证明错误不漏报、文件不误覆盖、停止能恢复、引用能追溯、用户授权不失效误用，再通过同条件样章比较证明修稿时间或质量改善。没有证据时不能宣称文学质量、爆款概率、收益或“去 AI 味”必然提高。

建议技术基线为 **Electron + React + TypeScript，Markdown 保存作品，SQLite 保存运行记录和索引，自建受限写作工具循环与确定性工作流**。这是待技术样机验证的推荐，不是用户已经指定的技术栈。Codex App Server 留作可替换执行器方案，首版不同时开发两套完整内核。

尚未确定的预算、时间、收费边界、实际模型能力以及文档中的产品选择，集中在第 10 篇。它们不影响本次分析交付，但其中的阻断项解决前不能声称“可以直接按固定工期开发”。
