## PlotPilot 深入到哪些链路

固定本地源码：`_analysis_plotpilot_20260910/source/PlotPilot-cbd260ba7b5fe35e53f528937c4a240fb67ea2dc`。研究记录的 GitHub 提交与该快照一致。

| 链路/文件 | 审读结论 |
| --- | --- |
| frontend/package.json、src-tauri/lib.rs、tauri.conf.json | Vue/TS UI，Tauri/Rust 外壳，Python/FastAPI 子进程；具有单实例、端口与生命周期处理 |
| engine/runtime/runner.py、writing_delegate.py | 运行生命周期、写作委派、暂停、审计与失败分支有明确拆分 |
| engine/pipeline/base.py 的 run_chapter 及准备/保存路径 | 生成前准备→生成→校验→保存→后处理；部分校验为警告；不能把整条链默认看作强制通过制 |
| chapter_aftermath_pipeline.py 的章后与辅助阶段 | 章后有主流程和辅助任务，若干失败仅警告；我们的完成语义必须自行定义 |
| context_budget_models/policy、allocator 构造投影路径 | T0/T1/T2/T3 分层可借鉴；抽取原定义的探针证实边界缺陷 |
| character_projection_service.py | 有确认/候选来源和角色状态投影；知情边界部分仍为空占位，不能当成完整实现 |
| ai_invocation/services.py 的调用/采纳服务 | 生成尝试与采纳决定分离值得借鉴；不能由命名推断持久化与故障原子性 |
| unified_checkpoint_service.py 的 checkout/_restore_chapters | 该恢复分支按章节 ID 保留/删除；未见在该函数恢复同 ID 旧正文内容，不能等同完整文件版本回滚 |

探针结果：T0 预算 15 时返回已用 15，却保留 25 单位；预算 10 时保留 30 单位。普通层对照能清除超额槽位。角色投影调用传 `bible_repository`，构造器接受 `unified_character_repository`，隔离调用产生 TypeError，改成正确参数的对照可通过。单位是探针设置的槽位 token 计数，不是实际模型 tokenizer 实测。探针不证明所有生产路径都会触发，更不代表整个项目不可用。
