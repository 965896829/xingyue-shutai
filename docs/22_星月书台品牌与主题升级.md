# 星月书台 0.3.2：品牌与日夜主题

日期：2026-10-09。基于 0.3.1 实施。此次范围为品牌、外观、窗口主题和安装身份兼容；写作流程、数据库结构、模型连接、记忆与规则功能沿用当前实现。

## 素材与布局

作者三张 JPG 原件保存在 `resources/brand/originals`。透明派生素材保存在 `resources/brand/generated`，处理提示记录在 `resources/brand/imagegen-prompts.json`；没有覆盖原图。图像工具用于去掉外围白底与提取独立图形/字标；导出脚本只负责透明留白裁切、尺寸归一化、PNG/ICO 编码。

第一张图生成固定应用图标，ICO 包含 16、24、32、48、64、128、256px。夜间使用第二张的月亮书本，日间使用第三张的星星书本。两种图形共享 512px 画布，底部与视觉中心对齐。侧栏展开时图形 56px、字标 116px；收起后显示 32px 图形，展开按钮独立保留。

字标采用同一份「星月书台」透明字形遮罩，仅切换深蓝/浅金墨色。这样保留定制字形，同时不让两套字体叠出重影。两种图形同时挂载并预解码，切换不触发换图请求。

视觉层次参考 [DeepSeek Harness 官方预览](https://www.deepseek.com/harness/)，采用轻边框和柔和面板；没有复制其品牌素材或替换现有写作功能。正文区保持干净，成功/警告/错误/差异继续使用语义色。

主动切换时明确过渡背景、文字、边框等颜色约 320ms，图形透明度/缩放约 480ms、最多 2%。不使用全局 `transition: all`。启动在 React 挂载前读取旧键 `wenxu-color-mode`，直接应用主题。连续点击取消旧收尾计时，CSS 从当前可见状态转向最终选择；编辑器和聊天组件不因主题重建。

系统减少动态效果时关闭缩放，使用约 50ms 淡化，窗口立即同步。原生标题栏使用相同 ease-out 曲线插值，动画中不写盘；结束或退出时只保存最终配置。`setAppearance` 的 `animate` 为可选项，兼容旧调用。
