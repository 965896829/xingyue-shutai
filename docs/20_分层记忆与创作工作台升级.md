## 迁移、升级与回退

1. 退出旧客户端后运行 `release/文序 Setup 0.3.0.exe`，或保留整个 `release/win-unpacked` 目录运行其中的 `文序.exe`。本次交付不替换 `D:/aiwenxu/wenxu-desktop` 内的已安装版本，也不打开真实作品进行试写。
2. 全局模型配置保持兼容；语义检索默认关闭，需独立填写连接。写作、提取和评估未分配时沿用当前写作模型。
3. 第一次打开 SQLite v1/v2 作品时，升级到 v3 前用 `VACUUM INTO` 备份数据库，包含 WAL 内容。作品目录产生 `.novelclient.before-v3-<编号>`，包含原数据库、历史对象、事务、正文与封面等普通附件，并附 `wenxu-backup.json` 校验清单。符号链接、Git、node_modules 与既有迁移备份不复制。
4. 未接受的旧 S10 候选保留正文，转入复核流程。已接受正文且停在 S11 的作品继续完成章后更新，不重新生成正文。旧候选若基础项目版本不同，仍需重新建立上下文。
5. 回退时先退出客户端，保留升级后作品。通过“导入、导出与备份”选择上述备份，恢复到新目录，再用旧版打开恢复副本。不要用旧版直接打开已升级的 v3 数据库，也不要只覆盖一个 SQLite 主文件。
6. 升级前没有完整快照记录的历史不能凭空重建。已有单文档历史仍可追溯；跨文件一致快照从迁移后的起点开始。

本次开发前建立了本地 Git 基线，改造位于 `codex/agent-kit-integration`。安装包不包含验收作品、模拟模型和 API Key。

## 实际边界

- 真实服务商的 embedding 质量、真实 LLM 的文学质量和市场资料准确性尚未实测；本轮未使用用户的付费 API。兼容接口不等于每个供应商都支持 `dimensions`，该参数默认不发送。
- 检索使用本地精确余弦扫描，没有 ANN 服务；人物视角使用精确检索回退，避免未过滤原文泄露。旧文件缺少来源或实体信息时保持缺失，不自动补造证据。
- 输入容量检查采用完整请求 UTF-8 字节保守上界，尚未接入各厂商专用 tokenizer。价格来自用户配置；没有完整回执时金额保持未知。
- 叙事分数是有来源的阅读判断，不是文学质量保证、平台流量或签约概率。评估不可用时仍可审阅正文。
- 修订影响队列采用保守失效标记；作者核对或修订候选后闭环，不宣称自动完成所有语义连锁修复。自由草稿沿用原能力，未增加完整分支管理器。
- 当前快照选择器加载最近 1000 个快照，曲线加载最近 500 条评估；完整历史保留在作品数据库中。长期作品的全历史分页曲线仍需扩展，容量回归不代表这部分 UI 已完成全量展示。
- 保留了大型前端 bundle 的既有构建提醒。本次未验证 Windows 11、真实断电、磁盘耗尽、全供应商组合或安装器跨版本矩阵。安装包未配置发布签名。

原 `docs/00—19` 保留为需求和历史交付记录；与本次状态冲突时以本文及当前代码、测试为准。
