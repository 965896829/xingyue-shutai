# 星月书台 · 网文写作客户端

当前源码版本 0.4.19。Windows 本地写作客户端，保留中文目录、Markdown 与四协议执行器，支持分层记忆、人物状态、叙事曲线和正文记忆联合接受。自然表达规则覆盖创作讨论、试写、规划、正文与修订，默认启用。SQLite 保存正式快照、任务、事实与提交记录，Markdown 通过可恢复队列同步。安装包与覆盖安装状态以本轮交付记录为准。

0.4.19 支持点击侧栏左上角“星月书台”文字或图标返回首页，收起侧栏后同样可用。未保存的文稿保留本机草稿并提示确认；运行中的任务需先停止或等待完成。作品可从首页重新打开。

0.4.18 将开书页改为“选方向 → 确认方案 → 定书名并开书”，每次聚焦当前一步，已完成步骤可回看。一般审核建议折叠且无需重复填写保留理由；重要冲突仍阻止继续。请求失败时显示实际状态并直接提供恢复入口；确认方案后可一次启动独立命名，选名与最终采纳仍由作者操作。见 [分步界面与验收记录](docs/refactor/creation-steps-0.4.18.md)。

0.4.17 将创意与标签开书统一到作品方案：比较方向、完善并确认结构化方案后，再独立生成或核对书名；书名承诺可追溯到方案，最后统一采纳，S01 仅推进一次。方案修订按未来章节生效，关联世界规则、人物约定、未来大纲细纲与包装核对，保留既有正文。独立改名不触发剧情修订。保留 11 阶段及旧作品主动接入，见 [统一作品方案与独立命名](docs/refactor/unified-creation-0.4.17.md)。

0.4.16 接入 OpenAI 原生 `web_search`。默认自动路由：Responses 模型使用原生搜索，其他协议沿用第三方搜索；也可指定搜索方式。原生搜索使用现有模型连接和 Key，沿用聊天联网开关，显示进度、可点击引用及历史来源。已通过本机现有 `gpt-6.1-sol` 连接的真实搜索；中转兼容模式不发送上游拒绝的次数限制参数，实际搜索次数由上游决定。普通创作阶段不自动联网，见 [原生联网搜索接入与验收](docs/refactor/native-web-search-0.4.16.md)。

## 运行

- 本次安装包：`release/home-navigation/星月书台 Setup 0.4.19.exe`。
- 本次解压目录运行：`release/home-navigation/win-unpacked/星月书台.exe`。整个目录需一起保留，不能只复制 EXE。
- 开发：Node.js 24，执行 `npm ci`、`npm run dev`。
- 本地生产构建：`npm run build`，随后 `npm start`。
- Windows 安装包：`npm run dist`；编译和打包均不需要作者提供 API Key。

安装包未配置代码签名证书。本版本没有账号、收费、云同步、平台直发、自动更新或遥测。

## 第一次使用

界面层次参考 DeepSeek Harness 官方桌面预览：轻边框、居中聊天区与圆角输入框。右上角“夜间 / 日间”切换深蓝黑与暖白外观，左上角月亮/星星标志柔和过渡，自动记住选择，保留输入中的任务、正文草稿和撤销记录。点击侧栏左上角“星月书台”文字或图标返回首页，旁边按钮可收起导航；“创作流程”展开 11 个阶段；点击文件或右上角“文稿面板”打开编辑与差异区域。

顶部标题栏、菜单入口和窗口控制与日夜外观同步。拖动顶部空白处移动窗口；“星月书台 / 编辑 / 视图”保留原菜单，F10 可聚焦菜单，Alt+W / E / V 打开对应菜单。窗口外观缓存独立保存在原应用数据目录的 `appearance.json`，不改动 API 配置。系统开启“减少动态效果”时使用短淡化。

新书进入“作品方案与书名”，旧作品保留原流程并可主动接入。圆形 ↑ 或 Enter 发送消息，Shift + Enter 换行，Ctrl + Enter 仍兼容；空消息和中文输入法选字不会触发发送。需要整章试写、阶段产物或正式修订时，先展示任务卡，作者点击“确认并开始任务”后才执行。“历史任务与阶段执行”保留原候选、差异及确认入口。

0.2.1 的聊天输入区参照 Codex 排布：左下「＋」打开创作工具和聊天引用，点击模型名搜索或切换模型，地球按钮切换本聊天的按需联网，右下圆形按钮发送或停止。输入框随内容增高，日夜主题与窄窗口均适配。[输入区改版说明](docs/19_Codex风格输入区.md)。

对话内容左侧增加横线导航：鼠标靠近时伸长，点击跳转任务、回复、候选和确认区，当前阅读位置高亮。供应商、作品和放弃候选使用展开式垃圾桶按钮，点击后再确认或取消。删除作品移入回收站，保留七天，可恢复；到期自动永久删除本地作品，客户端关闭期间到期则下次启动清理。独立备份不随之删除。

1. 新建作品，选择保存目录、填写创作想法或选择标签，此时不填写书名。点击“创建并开始”后，在“选方向”比较三个故事；选定方向、确认或调整关键假设后完善方案。“确认方案并生成书名”进入命名步骤，也可选择自己取名。选好书名后统一保存，S01 仅推进一次；可取消勾选“保存后继续生成”，留待稍后启动 S02。已完成步骤可回看，一般建议在详情中展开；服务中断后可在当前页继续，结果未知时需先确认是否重新请求。未配置模型时先保存作品，配置模型后再生成方向。
2. 打开“模型与连接设置”，添加供应商，选择协议并填写 API 根地址和 Key，自动获取列表后勾选多个模型，也可手动添加模型 ID。保存后，它们均可在写作区选择。连接与 Key 共用，每个模型的容量、价格和测试结果分别保存；每次任务使用其中一个模型。根地址通常以 `/v1` 或 `/v1beta` 结尾，不能再填写完整的 `/chat/completions` 路径。
3. 保存配置后，分别做文字和工具续轮测试。测试会实际调用你的服务商；本机 Sub2API 的 Responses / gpt-6.1-sol 已通过文字和工具续轮测试；其余端点需各自验证。
4. 在“创作讨论”选择模型并直接交流。每本书可以新建多个主题聊天；正式资料共享，其他聊天的未采纳方案只在明确选择引用时读取。需要执行时审阅任务卡再确认，正式结果进入原候选区。
5. 自由试写可保存到独立草稿区，编辑并保留版本；转为正式资料先建立修订任务卡。正式候选仍需修复阻断、审阅后接受；旧候选可“重新检查候选”，不调用模型。每章正文仍需授权。
6. 在“记忆与连续性”查看人物、旧伤、伏笔、来源和历史快照。语义检索在“智能体与联网设置”中独立配置；默认关闭。作品设置中可分别指定写作、记忆提取和评估模型。
7. “作品设置 → 自然表达”默认启用提供的去 AI 味规则库；讨论每轮加载通用表达规则，试写、正文和修订加载叙事规则。“题材与场景”可增加本书所需模块；关闭只影响之后的请求，既有内容不自动重写。

模型不支持工具调用时不能完成 Agent 工作流，返回一段文字不算阶段完成。遇到结果未知的请求，客户端不会自动重发。任务变大时可停止后用所选模型重新组装上下文；原任务与原生协议数据仍留作记录。

角色编辑、搜索配置、任务卡、数据库升级和实测边界见 [智能体 0.2.0 交付说明](docs/18_智能体对话与执行分离.md)。

## 文件、备份与旧稿

- `.novelclient` 包含任务数据库、不可变历史对象、恢复日志与写锁，不要手动删除。
- 外部修改会显示待确认；任务接受前再次核对版本，旧候选不会覆盖新稿。
- 编辑器自动保留未提交草稿；“保存候选”不立即覆盖正式文件。
- 从“导入旧 Skill 档案”预览后创建独立副本，明确选择继续位置；旧角色、台账的来源须核对。
- MD/TXT/DOCX 导入先预览。复杂修订、批注、图片、域和版式不保证无损。
- 自动备份目录按作品设置；完整备份包含作品、控制数据库和历史，不包含全局 API Key。恢复创建新目录。
- 封面单独配置图像端点，生成背景后本地叠字。PNG 与文字配置单独保存，可再次打开调整。

## 验证命令

各脚本的用途、执行条件和维护范围见 [脚本入口说明](scripts/README.md)。默认回归、专项性能测试和历史验收工具分别列出，避免将一次性验证当作持续测试。

```powershell
npm run check
npm test
npm run test:scale
npm run eval:context
npm audit --omit=dev
npm run dist
```

`test:scale` 在系统临时目录创建 1200 章、300 万字合成作品，报告写到 `.test-output/scale-report.json`。这验证容量，不证明模型写作质量。`scripts/mock-model.mjs` 只监听本机 `127.0.0.1:19452`，用于界面测试，不是生产服务。

若 Electron 下载环境无法直连 GitHub，可临时设置 `ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/`；下载仍使用 Electron npm 包内校验和校验。不要关闭 TLS 校验。运行目录可通过 `WENXU_DATA_DIR` 选择独立的全局设置目录，用于隔离测试或便携部署；作品目录仍由作者选择。

## 已知边界

- 文学语义、近音重名、角色动机、证据是否真正支持结论等依赖原 Skill 规则、模型审阅和作者确认，程序字段检查无法证明这些事项正确。
- 修订影响分析采用保守待核对范围，不能把“文件哈希改变”直接当作“语义必然受影响”。
- 记忆结合实体编号、别名、一跳关系、中文词法与可选语义检索；持续约束单独保留。启用语义检索后，所选范围的已接受资料会发送到作者配置的独立 Embedding 服务。
- 普通写作与研究工具不提供终端执行能力。市场检索使用现有公开搜索连接与限额。
- 配置、文件和正文确认的可靠性有自动化测试；真实服务商协议变化、网络故障、真实断电、磁盘耗尽和跨 Windows 版本安装升级需额外环境验收。

详细范围、没有验证的要求和剩余差距见 [180 项逐项实施状态](docs/15_逐项实施与验收状态.md)。未验证事项不自动视为通过。
