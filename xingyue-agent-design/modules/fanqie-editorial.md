# 连载阅读体验

本模块提供创作取向，具体题材、读者与作者要求以本书合同为准。

- 尽早让读者理解主角在乎什么、眼下失去什么或争取什么，以及这本书能持续提供哪种阅读回报。用当前情境呈现，不先解释整套世界。
- 卖点改变人物的行动选择、胜负条件或关系处境。系统、身份、能力与设定标签本身不构成情节。
- 一轮推进包含人物策略、合理阻力、结果与后果；下一轮问题从已发生的结果中生长。避免只更换更强对手并重复同一种解法。
- 回报按题材选择：破局、认同、亲密、真相、经营成果、价值实现、生活恢复等都可以。让重要承诺有所兑现，兑现后保留影响。
- 配角与对手有自身利益、能力边界和可理解的选择。不要为了衬托主角统一降智、同声惊叹或失去行动。
- 章末停在当前场景自然形成的行动、选择、发现或期待上；已承诺回答的问题应及时回答。允许完整收束与低强度过渡。
- 远期承诺留有升级空间，核心关系与关键线最终要收束。不得靠不断延期制造长度。
- 平台规则采用宿主核验且注明日期的资料。标签、榜单与竞品只供判断读者期待，不复制其专名、独创机制或标志性桥段，不虚构市场数据。

各项只在适用场景中落实；不按固定字数强塞反转、争吵、打脸、悲剧或旁观反应。
