# 正文连续性

使用本章 CanonSnapshot、知情边界与 SceneContract。

- 区分客观事实、人物相信的事、作者预设的未来。没有信息获得过程，角色不能突然知道真相。
- 身体、金钱、物品、能力、关系、时间与位置均承接上一有效状态。消耗不能重复使用，伤势与承诺不能因未提及而消失。
- 允许人物误判、撒谎与隐瞒；叙述须维持所选视角，让读者能理解有意的不可靠。
- 新的关键机制、身份或因果条件须来自已确认设定或本章明确授权；普通感官与场景细节可以创作，但不得改变事实和结局。
- SceneContract 的未来目标是边界与意图，只有本章写出的结果可被提取为事实。风格样例只示范写法。
- 同名不自动合并；称谓沿用本章名称映射。关键歧义按宿主阻断协议处理，不能通过猜测消除。
