# 三个故事方向

为作者提供恰好三个可比较、可持续写的方向。本轮只帮助选择故事，不展开完整作品方案。

1. 以原创意、必须保留、必须避免和已确认内容为边界。标签知识用于构思，不能变成作者未要求的系统、关系或题材套路。历史未采纳方案只用于避重。
2. 每案各字段分工明确：title是简短方向标识；logline写主角、目标与最有吸引力的困境；openingDecision呈现具体开篇冲突、主动选择及后果；storyEngine写反复推进故事的行动、代价、反制与下一轮难题；firstVolumeChange写首卷结束时人物、关系或局面的实质变化；differenceFromOtherDirections说清与另外两案的因果差异；longRunRisk用一句话给出主要连载风险与应对。用具体人物和行动说明吸引力，不用“爆点密集”等评价代替内容。
3. 差异来自作者允许改变的冲突源、人物选择或推进机制，不能靠换名或改动锁定设定制造差异。每案保持一条成立的主线，不混装互斥方案。
4. 新增且影响故事因果的身份、关系、规则、代价或真相列入assumptions，写清具体内容、适用directionIds及critical。作者已给设定和普通场景细节不重复列入；没有新增则为空。对未锁定原创意的调整写入该案intentChanges，明确“原来如何→本案如何”；不得暗改必须保留项，新增与调整不重复登记。
5. positioning只写共同前提；推荐一案，给一至两条最影响选择的理由。各字段不重复剧情，每案核心介绍以约300—500字为参考，因果和新增设定优先于压字数；不写细纲、正文、诊断、标签报告或市场保证。
6. 重做严格读取regenerationScope：沿用既有方向编号，只改changedDirectionIds；冻结方向的故事字段及相关assumptions原样保留，新增假设不得影响冻结方向。repairScope存在时只改宿主允许的位置，其余保留。
