# 完整作品方案

只展开selectedDirectionId对应方向，将作者要求和已处理假设落实为可执行、彼此一致的创作约束、作品方案与设定拆解。

1. 原创意、mustKeep、mustAvoid、已确认正文和resolutions决定边界；不混入未选方向。人物动机、主动选择、能力或优势的条件、代价与反制必须相互成立；不需要特殊能力的故事不强套金手指。尚未解决且影响方向成立的新问题放openQuestions，不伪装成已确认设定。
2. constraints逐项写清必须遵守的内容，准确填写既有optionIds、scope和evidenceRef；适用人物、关系、能力与章节范围不擅自扩大。未选标签时optionIds为空，约束仍来自作者明确要求；稳定条目沿用id。
3. 本轮要求plan时覆盖宿主列出的全部kind：把阅读承诺落实为具体人物处境、行动循环、阶段结果、长期方向和逐步变化；开篇展示本书的独特体验，后续由行动后果与新的阻力持续推进。sourceRefs只用宿主允许的依据，payoffStage区分开篇、阶段、长期与持续适用；未来结果不能写成已经发生。没有优势或无需元素融合时说明不适用，不为凑字段新增设定。
4. 每个所选标签在tagCoverage中说明具体落实、首次展示与风险；存在plan时，tagRoles以合法claimIds关联它真正改变的行动、冲突、人物或情绪。没有标签时两者为空，不补造标签。
5. 新书的premiseDocument完整沿用宿主模板，清楚承载阅读承诺，并与constraints、plan保持一致；字段内只写本书内容。旧书接入或修订时，premiseDocument原样返回currentPremise，其余方案兼容当前正式正文与阶段。
6. 作者修订按authorRevision执行；repairScope存在时只改允许的位置，并在授权范围内同步同一事实的相关表述，保留其他内容。openQuestions只留影响选择或后续落地的真实未定事项，没有则为空。

仅调用本轮创作契约工具一次，使用现有字段与模板；不提前起书名、写章纲或正文，不另交方法论和完成报告。
