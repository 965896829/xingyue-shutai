# 人物记忆三章演示

## 14 三章人物变化示例

以下为原创演示：许知野和妹妹许禾共同经营失物招领处。哥哥重视给人留余地，但常替家人做决定；妹妹重视对账与独立，也关心来认领物品的人。人物内核已由作者确认。

第一章，哥哥把当天收入交还给认领旧饭盒的周婶，却没有先处理电费。妹妹看到停电通知，合上账本，仍帮周婶把饭盒装好。系统记录归还收入、缴费缺口、妹妹看到通知和继续帮忙。正文没有明确的内心时，“愧疚”“感恩”等解释保留为候选，不能直接写进角色事实。

第二章，哥哥在门外看见妹妹从抽屉取出租赁广告，摊在工具箱旁。他正想进门询问，又退开。妹妹以为他没看见，并在内心决定先攒自己的店。哥哥知道她看过广告，可以怀疑她考虑租铺，但不知道她已决定独立开店；妹妹持有“哥哥没有看见”的信念；开店是未来目标。哥哥提出大额开支共同决定，妹妹是否接受仍取决于后续回应。

第三章，有人出钱让他们销毁认领登记。哥哥先把条件交给妹妹一起判断。妹妹拒绝这笔钱，提出公开收费的查档服务，两人达成约定。系统更新共同决定和经营规则；妹妹的独立目标保留，关系也不会仅因这次合作变成无条件信任。

来客也属于实际出场角色，保留稳定临时身份并记录报价与要求；缺少内心依据时，心理维度记为依据不足。

如果作者删去第二章哥哥看见广告的段落，他获知租铺信息的记录和依赖这条记录的场景包失效。妹妹的目标仍然存在；她的信念与真相的关系重新计算。第三章已采纳正文保留，并按实际依赖显示需要复核的地方。
