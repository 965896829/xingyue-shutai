# 评测与验收方案

以下为建议验收设计，不是已取得的性能或读者成绩。

## 现有基线

0.4.82 的eval:prose是无模型的文本线索及证据定位回归，明确标记literaryQualityVerified:false。保留它；新增真实生成回放、人工盲选与真实读者反馈，分别报告。

## 实验分层

A0 当前0.4.82固定配置。
A1 仅采用A版专项提示词。
A2 新编译器减负＋短命名；不改模型和故事输入。
A3 加入版本化文风与同场景正例。
A4 在A3上增加有证据的局部修订。

一轮只改变一个主要变量。随机左右展示且隐藏模型/版本；保持作者要求、故事事件、输出长度范围和采样配置可比。更换模型单独实验，不能把模型提升算给提示词。

## 样本与问题

建议先准备30个原创或获授权场景，覆盖项目实际支持的主要题材，以及开篇、冲突、关系、日常、过渡、高潮余波。另选若干连续3—5章样本检验跨章声音和因果。数量为启动规模，随后依分歧与不确定性扩充；没有样本时先用原创场景，不能冒称已评测用户作品。

每个样本保存作者原始要求、事实与知情、必要剧情结果、风格偏好、模型参数、prompt/source hash、生成原文、延迟与用量。事实/知情/冻结违规先单独判断，不能被风格平均分抵消。

盲评问题：
1. 更愿意继续读哪版，还是无差别？
2. 人物是否像有自己的目标，哪处选择或回答支持判断？
3. 哪句话让你出戏、看不懂或觉得被反复解释？
4. 人物对白能否辨认，辨认依据是否超出口头禅？
5. 回报是否兑现，章末期待是否自然？
6. 你愿意把哪段作为本书声音样例？

至少保留作者和目标题材读者的意见来源；不同读者意见分别记录。模型评委只用于筛查和定位，不能替代人类偏好，也不能用同一模型自评证明成功。

## 指标

工程：结构成功率、硬要求违规率、来源/知情错误数、越界修订数、冻结保护、实际调用数、输入/输出/缓存token、首个可读内容时间、最终可采纳时间、成本。
编辑：成对偏好胜/负/平、人物真实感、声音区分、因果可读、过度解释、承诺兑现与重复场面，均须给原文证据。
产品：作者采纳/定点修改/整章退回比例，需同时记录任务难度与模型。
市场：真实曝光到阅读、章节读完/追读、评论与追更，使用平台实际定义和章节版本；不造阈值、不混淆人群。

## 建议放行条件

硬约束与冻结回归必须零新增失败；版本/来源错误必须修复。相同样本下成本或延迟改善且关键质量不退步，再逐步扩大试用。盲评如预设目标偏好率60%，应明确是内部实验目标，报告有效样本、平局、分歧和区间；样本不足时不能据点估计宣告普遍优胜。不要把所有标准压成“爆款95分”或AI率0%。

## 费用与授权

离线测试不使用真实密钥。真实模型回放只在指定隔离项目、明确provider和预算后执行，持续记账且可停止。用户作品样本不随评测日志公开上传；正文与凭据分别管理。
