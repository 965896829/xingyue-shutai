# V4 实施顺序

| 批次 | 主要工作 | 完成依据 |
| --- | --- | --- |
| 第 0 批 | 建立能力目录、操作解析、静态验证与旧 ID 映射 | 旧任务行为不变，未就绪操作无法激活 |
| 第 1 批 | 实施 V3 增量记忆与来源、时间、事务边界 | 同版正文与记忆、稀疏更新、修订回放通过 |
| 第 2 批 | 接入人物动态、覆盖与入场状态 | 人物误信、章内顺序、未知与无变化可验证 |
| 第 3 批 | 检索、实际读集、查询依赖、修订与水位 | 穷尽查询、分支、来源失效与恢复通过 |
| 第 4 批 | 共创对象、VoiceSlice、19 包操作与画布 | 局部采纳、面板数据一致及文风盲评完成 |
| 第 5 批 | 可控扩展与技能离线改进 | 导入范围、版本回退、成对评测与成本可追溯 |

第 0 批是轻量接入基础，可以与记忆工程并行，不改变 V3 的记忆优先顺序。创意、文风等已有任务可先使用兼容资源试验；大规模调整阶段输出前，必须完成 adapter、schema、采纳、恢复和 UI 的同批迁移。

保留 A 路线的 26 份技能与五份创意命名资源。旧创意、完整方案和标题有自己的格式版本与资源指纹，不能用一个全局技能 hash 把所有任务绑定在一起。新滚动规划、纯正文传输、结构化对象与增量记忆分别用工作流版本开关启用。[V4C14]
