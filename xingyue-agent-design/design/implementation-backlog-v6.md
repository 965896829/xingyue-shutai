# V6 实施清单

## 实施入口

先读取实际仓库适用的 AGENTS.md、package.json、当前 HEAD、工作区改动与已有测试入口。V6 的审计基线为 0.4.82 / b505f6f459db74871f39f63acf6106b827c8a353，当前实现可能已经前进；逐项确认已实现、部分实现、未实现，保留用户改动。

V6 继承 V5 平台、世界、书名和可视化，以及 V3 记忆和人物合同。以下顺序把质量验证提前到核心实现过程中，不重新启动一套架构。所有新 operation 使用真实输入输出 schema、adapter、权限、范围和工作流版本注册；设计注册表不可直接激活。

## A 核心状态与质量基线

| 工作 | 完成条件 | 证据 |
| --- | --- | --- |
| A1 正文与记忆 | 一章正文 有版本的批量增量 原审核 同版采纳 下一章查询贯通 | 实际事务 读集 水位和撤销记录 |
| A2 人物覆盖 | 实际出场者有变化 无变化 依据不足等覆盖结果 | 原文引用 角色身份 章内顺序 |
| A3 实验记录 | 固定样本 模型 prompt 上下文 预算和产物版本可追溯 | 可重复运行的隔离评测入口 |
| A4 对比基础 | 文风与创意实验分开 展示顺序和结果保存 | 匿名候选 平局 弃权 排除原因 |

阶段验收先完成 V3 的必要事实、误信、空结果依赖、旧章修订与分支案例，再运行小批真实样稿。结构检查和无模型夹具不能标为文学质量通过。Promptfoo 可接现有模型网关；没有真实 provider 和明确预算时，先完成本地层并明确剩余范围。

## B 声音与编辑证据

本地保存选择与改前改后差异，绑定作品、角色或叙述声音、场景、正文版本和作者说明。未知原因保持未知，纠错不直接进入文风偏好。撤销证据会使依赖它的偏好候选失效；已生效档案需要版本化复核，不静默删除作者确认内容。

实现 voice-calibration.learn-edits 产生偏好候选，沿用 update 应用已选择的档案变化。VoiceSlice 只检索同类场景和适用对象的证据，作者原句及必要剧情结果受保护。审稿与修订区分故事依据、场景用笔和表达问题，修复范围与权限一致。

验收必须包含：一次删除心理段落不会形成全书禁令；人物 A 的说话方式不会套到人物 B；纠错、未知原因、混合修改不会冒充稳定审美偏好；原证据撤回或正文变更后引用不漂移；表达修订不暗加人物身份、能力或事件。

## C 探索与试演

| 工作 | 完成条件 | 关键边界 |
| --- | --- | --- |
| C1 创作授权 | 必须保持 当前偏好 允许探索分别编译 | 作者可明确改旧锁 其他锁继续有效 |
| C2 空作品探索 | 真实空基线允许场景或对白起步 | 不伪造世界与正文版本 不要求全部规划 |
| C3 探索草稿 | chapter-draft.explore 输出分支草稿与关键新增 | 普通细节依授权 重要前提可追溯 |
| C4 单角色回合 | co-creation.rehearse 仅获角色可见包 | 真相标签 导演指令和角色观察分离 |
| C5 回放和转换 | 回退 编辑分支 比较 转换为变更候选 | 不直接写正史 不复用过期增量 |

试演采纳首先核对目标当前基线与授权版本，再解析局部身份、依赖闭包和冲突。最终正文若发生变化，对最终 hash 重新审阅和提取核心记忆。结果未知的模型请求不盲目重发；每个生成回合和修复计入总预算。浏览已有分支和撤销布局不调用模型。

## D 初读与阅读体验

实现 reader_prefix 专用编译器、总控和共同方法替换。隔离覆盖系统、工具/schema、附件名、缓存、历史、检索和错误返回。完整作者合同、作者真相、后续计划、隐藏字段标识与宿主私有证明不得进入模型请求。标题简介按实际呈现的版本和截止位置处理。

first-read 使用独立请求，模型可见包与宿主核验记录分开。输入只覆盖部分时返回明确覆盖范围；无可靠完整前缀时不能宣称完成整段初读。用一次性 canary 与实际请求捕获检查全部表面，再验证缓存命中和跨角色/跨分支切换。提示词中包含禁止语句不算隔离已实现。

阅读体验由既有承诺、正文揭示和事件派生，区分作者计划、文本证据、模型解释和真实反馈。模拟意见不能进入真实读者统计。可选投影使用可独立解析的附属载体，损坏后可重建；核心记忆仍必须正确就绪。

## E 剧情解法与工作台

从已采纳场景派生冲突、策略、回应、解法、变化与回报。检索保持范围和水位，canon-audit.patterns 只对实际返回且有来源的场景比较。支持有意回响、能力复用与承诺兑现；不以相似度自动改稿。

接入对比试读、声音证据、试演分支、阅读轨迹与解法比较视图。复用已有 React、人物 SVG、世界画布和查询基础设施；没有实际需要不增加图形运行库。可视化只读派生状态，语义修改回到统一 ChangeSet。

V5 的分类入口、动态模块、S03 固定八栏迁移、标题证据和现有节奏视图同步落实。旧模板、schema、validator、workflow 与 renderer 必须整体迁移，不能只更新提示词。

## F 实际作品验收与发布准备

执行约 30 场景启动集、连续 3—5 章、代表性长篇回放、旧作品迁移和目标读者盲评。按作品或创意族划分保留集；反复测量按参与者与作品分组，保留平局、弃权和无效原因。比较模型时只归因于实际改变的变量。

反馈分析以宿主计算的分层统计为输入；reader-feedback.compare 解释证据和替代原因，不创造样本量、置信区间、真实留存或市场结论。作者、目标读者和模型模拟分别呈现。文学建议不能作为自动拒稿门槛，硬约束和数据损坏单独检查。

每批交付真实文件变化、运行命令、通过结果、未运行项、迁移和恢复方式。性能门槛先依据测量确定；未测的百万字、Windows 发布和平台商业结果不写成已通过。完成一批后按依赖推进，避免停留在接口占位或 TODO。

## 回退与兼容

V3、V4、V5 在途任务固定原资源版本，V6 仅由新工作流进入。注册核心变体和方法替换时要求实际 adapter 能证明输入语义相容。缺少新投影不破坏旧文稿阅读；缺少正文核心状态只阻断依赖它的正式续写和采纳，不阻断讨论、手写编辑或隔离探索。

停止和回退保留实际请求、产物及原始反馈，采用新修订记录而非抹掉历史。迁移遇到未解析身份和来源时，保留原文与待决状态，不默认合并角色或推断作者决定。
