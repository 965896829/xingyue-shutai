## 产品目标

产品面向番茄长篇网文，支持有辨识度的创意、因果与人物动机、自然表达、持续阅读期待和百万字连续性。作者对题材、设定、人物、剧情、文风和探索范围拥有最终决定权。题材分类推荐合适的世界模块，作者可使用自有体系、混搭和暂不确定，不强制境界、金手指、代价、创伤、秘密或相同节奏。

采用本地模块化单体。保留 Electron 的独立 utilityProcess 写作内核、TypeScript、Pi、SQLite、不可变内容对象、统一模型与工具网关、候选、正式采纳及恢复。当前没有迁移到 LangGraph、Temporal、常驻角色群聊或外部图数据库的前置要求。

## 先确认已有工程

当前审计已发现 SQLite 权威事务、候选审批指纹、CAS、Outbox、项目写锁、模型发送意图与预算账本、工具回执、版本化恢复、独立内核握手和增量快照。请在实际 HEAD 核对并复用，不能再造竞争的状态源。

Pi 是回合适配，保持宿主拥有规范请求、原生消息、费用、工具权限与正式提交。现有 `maxRetries: 0` 的目的，是不叠加第二层未纳入宿主的自动重试。网络恢复仍由统一网关处理，远端未知不能冒充未发送或费用为零。

现有 `runtime/operations.ts` 管理 UI 命令幂等回执；新能力注册表描述动作处理器和合同，两者职责不同。26 个现行技能资源与 19 个 V6 设计包也不是同一张运行表，不把 26 直接改成 19 后删除旧映射。19 包、48 操作、50 绑定与既有 112 项提示词来源保持设计含义；数量不代表 Agent 或请求数。

## 按 R0—R5 实施

**R0 固定恢复契约。** 记录实际基线与已实现矩阵，复用相关 runtime、crash、memory-safety 等测试，建立必要的请求和候选回放样本。验证重复操作、未知请求、停止后迟到结果、过期候选、数据库提交后文件待物化和老任务恢复。

**R1 无行为变更拆分责任。** 抽出开书、章节、讨论、修订 workflow 与应用命令处理器。执行层、模型能力适配、领域数据和正式提交分开，保持同一输入的调用、预算、候选范围与恢复行为。工具效果由显式合同声明并由宿主实现核验，不依赖名称前缀猜测。

**R2 接通版本化任务与上下文合同。** 复用现有作者授权、读集、快照、分支与预算，明确 schema、handler、prompt、工具、读写范围、验证和恢复。任务依实际必要资料放行，S01—S11 继续用作推荐路线。author、reader_prefix、character_turn 的隔离覆盖完整发送请求、历史、检索、工具、缓存、原生会话、附件和错误反馈。

**R3 完成一章业务闭环。** 沿用现有正文、审稿、记忆与采纳链，为章前状态、批量人物变化和同版投影补齐 V3/V6 领域合同，不重造并行流水线。最终正文改动后重绑核验与记忆，不沿用旧正文 hash 的结果。人物出场允许变化、无变化、依据不足和仅提及，不为每个角色启动常驻 Agent。叙事领域事件与运行事件分别保存。

**R4 根据测量优化长篇。** 针对当前事实全量重建、全事实查询和重复来源验证，先测量再做增量更新、可索引字段、局部查询及同源校验复用。增量结果与全量参考一致，并保持重建路径。既有 delta-v1 保留。体积测试与真实长期连续性验证分别报告。

**R5 按依赖开放 V6 能力。** 接入作者声音与改稿学习、探索、人物排演、读者首读、剧情解法比较、真实反馈及世界与交互工作台。按需调用，使用同一预算与候选体系。真实样稿、连续章节、真人盲评及发布验证按条件执行并报告，不把本地夹具当成作品质量结论。

本批结束后按依赖继续实施。相关能力已在实际 HEAD 完成时补足必要证据并前进，不重复重写。只有影响当前正确性或必要授权的缺口才阻塞对应操作；可继续的本地实现和验证先完成。

## 不可回退的产品行为

- 正常三方向保持一次模型请求与一次提交；局部重做冻结项保持原样，失败修复与用户重做分别记账。
- 作者已经明确授权的可回退候选修改直接执行，不新增重复确认；正式作品仍通过宿主采纳入口。作者可以明确修改旧锁，宿主更新授权版本与依赖。
- 实际发生、未来计划、人物信念、系统推断、讨论候选、探索、文风样例保持各自语义。界面投影不成为第二份可独立覆盖的真相。
- 作者、读者、角色的整份请求分别编译。角色误信使用该人物真正持有的信念，不能附作者真值或隐藏的真假标签。
- 正文、核心记忆和必要人物变化同版采纳。可选阅读与解法投影使用独立可解析载体，允许重建；核心缺失不能伪装成功。
- 面板打开、切章、筛选、回放和拖动布局不调用模型。修改关系或世界语义形成版本化 ChangeSet，进入统一依赖与采纳流程。
- 每次生成、审稿、修复、初读、角色回合和评测调用计入所属预算。停止、恢复和结果未知语义覆盖所有新入口。
- 旧任务固定原资源、合同与执行版本。没有语义兼容适配时保留可读和可导出状态，不把旧检查点交给新流程盲跑。
- 代码保持直接清晰，不新增解释性注释；必要许可证与第三方版权声明保留，工程说明写入文档。

## 提示词与激活

仓库 AGENTS.md 约束开发过程；产品 runtime/agent.v6.md 及 reader-prefix、character-turn 是写作模型资源，不混用。V7 为这些资源提供架构接入规则，不要求把全部架构文档追加到每次模型请求。

单任务装配一个适用总控变体、所需共同方法、当前操作和必要资料。coreInstructionsOverride 必须实际替换；历史 sourcePromptIds 仅追溯。新 registry 仍是停用设计，只有真实 schema、adapter、授权、验证、持久化、恢复和界面均接通后才可启用对应操作。禁止空接口、成功占位、切 active 或仅改提示词后宣布完成。
