# 分阶段实施与迁移

当前实施顺序以 implementation-backlog-v3.md 为准。本文保留原产品能力和前序迁移参考；记忆、人物认知、来源位置与修订细节按 V3 合同适配。

本包只交付审计与设计。A为现有输出合同兼容的候选提示词；B为需要程序配套的vNext设计。均未安装到当前客户端。

## P0 修复确定性问题并减少无关指令

- tags.ts 的冻结设定集合改为复用 planningRegenerationScope；局部重做保持方向ID集合，对所有未冻结返回内容执行语言检查。测试冻结全局/共享设定被删、被改、新增、换ID绕过。
- 在request compiler层分开purpose，而非把所有planning调用共用一套不断增长规则。先调expression-rules，再精简loader重复内容。
- skill.ts将prose命名改为当前实体名与称谓映射；S09解决必要新名。保留已有review/memory短命名保护。
- narrativeStreamInstruction与preview真实开关一致。先允许关闭后不注入节点指令、不等待曲线；再做sidecar。plan/final/checkpoint合用明确预算并分别记录。
- 采用A提示词时重建技能registry和资源锁；保存旧资源包，不能改变在途任务的promptHash后继续旧输出。

## P1 让文风与编辑可执行

- 从现有十维Markdown映射VoiceProfileV2；保留原文与解析置信，未启用继续未启用，不能自动激活。
- 现有voice-profile已有同事实短对比思路；把它接入可见的选择记录、profile版本和正文编译，建立“输入实际包含哪个版本”的可验证链。
- S09产出参与角色IDs；character-voice按ID选择、别名兼容；知情事实和说话习惯分开。
- 综合审稿沿用五个checks，声线问题归人物一致性，解释/句式问题归信息落地。需要V2 findings时增加适配器，不能直接添第六项。
- 局部修订新增baseHash与精确范围patch；宿主物化完整候选，全文结构/字数检查和受影响语义重审，失效旧review及memory。
- B版若启用正文独立阻断出口，新增report_stage_blocker的schema、provider路由和非正文落盘；成功仍纯正文，只有明确硬冲突可调用。适配未完成前保持A版writer空工具和原异常路径。
- 扩展eval:prose为真实模型回放与人工盲评；保留现有纯本地信号回归，不混报两种成绩。

## P2 滚动规划与长篇状态

- 新增workflowVersion=rolling-v2，并把批次归档窗口与近期细化窗口分开。旧项目仍完整批次门槛。
- 使用requirements/SceneContract/PromiseLedger作为现有权威数据的结构化投影；正文、确认记录与SQLite事实不新增第二套真值。
- 记忆提取由每次九份全文迁移为相关实体/义务增量＋精确来源；宿主物化Markdown。不可用摘要代替所有有效事实。
- 方向格式V2将故事核心与整批比较分开冻结；局部重做只返回变化项，宿主合并后完整验证。旧报告维持原结构。
- 新增题材/平台资料卡的发布日期、适用范围、过期提示；真实反馈附版本与观察窗口，人工导入作为无平台API时的默认入口。

## P3 商业与长期质量实验

- 同题材固定输入做开篇、高潮、关系、日常、过渡等多类评测。
- 包装与正文承诺一致性单独检查；真实入口实验与追读数据分别记录。
- 作者认可后的正文片段可进入本书正向风格样例。模型自动好评不能更新全局风格。
- 卷末/完结核对核心承诺、伏笔、关系与主线收束；形成可定位的修订单。

## 发布门槛

必须有旧任务恢复、来源版本竞争、预算继承、候选不污染正史、冻结改动保护、纯正文出口、原模板、资源锁、跨供应商协议与流式取消的回归结果。新增文风默认值必须有作者盲评证据；结构测试通过不能替代文学效果。

作者自定义agent.md不能被升级覆盖。保留原规则、配置、待选候选和作品版本；采用side-by-side资源版本和feature flag，选择新模式时固定其规则版本。回滚恢复上一资源与编译器版本，已接受正文不自动重写。
