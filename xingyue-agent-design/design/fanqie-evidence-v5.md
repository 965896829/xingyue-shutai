# V5 番茄题材、标签与书名证据研究

核验日期：2026-10-29。范围：公开官网、公开书库前端实际使用的无登录分类返回、公开排行榜、公开作品详情。没有访问作者登录后台，没有调用写入接口，没有下载小说正文，没有绕过验证或字体保护。

## 1. 最关键结论

本轮取得了当前公开书库的完整返回：男频 154 个阅读分类与标签，女频 182 个，共 336 个带频道的选项。主分类分别为 19、21，共 40 个频道入口、36 个去重平台 ID。公开排行榜的目录另有男频 19、女频 18，共 37 个频道入口、34 个去重 ID。两个集合不能混为一谈。

项目的现有 154 个阅读标签，其分组与名称与本轮公开书库男频 154 项完全一致。可以补充一份带来源与时间的外部 ID 映射。现有本地 ID 必须保留，不能重新按排序生成。这个核验只覆盖男频公开书库，不使现有 328 个内容标签、作者端完整选项或发布限制自动成为已核验。

番茄 2026-08-24 官方公告明确：原作品标签改名阅读标签；另增独立内容标签，内容标签仅作者后台可见，具体数量和必选设置以作品标签页为准。因此，产品可以对已核验的公开书库显示完整目录，同时把作者端内容标签作为独立、有来源、有覆盖状态的目录维护。不要把公开榜单的 37 个入口宣传成“番茄所有题材和标签”。[V5F01][V5F02][V5F06][V5F07][V5F08]

### 选择规则的适用范围

2026-03-16 公告说明原作品标签的主分类必选且仅一个，主题、角色、情节各可不选、各最多两个。2026-08-24 公告说明这套标签改名阅读标签，原分类、功能和规则不变；新的内容标签有独立池和独立选择规则，具体数量以作品标签页面提示为准。公告适用于原创长篇网文。不要把阅读标签的数量限制复制给内容标签。[V5F01][V5F02]

产品内部的自由创作题材可以多选、混搭、自定义或暂不确定。发布平台主分类与标签作为另一个映射视图，在准备发布时检查其有效规则。内部创作并不需要因平台主分类只能一个，就禁止用户组合都市、仙侠和悬疑。

## 3. 本轮交付的数据

### v5-fanqie-taxonomy-snapshot.json

包含两个公开书库频道的 336 个条目及独立的 37 个榜单目录条目。只保留事实性的 ID、分组、名称与来源，不重发官方全部释义。每个选项键包括平台、surface、频道、分组和平台 ID；同名或同 ID 不会跨频道与表面静默合并。

每个 surface 记录 URL、抓取完成时间、源文件 SHA-256、返回数量、完整性范围、是否覆盖作者后台和内容标签。数量不足、响应异常或未来 schema 改变时，刷新不能将旧条目批量删除。

### v5-fanqie-male-reading-crosswalk.json

154 个现有本地阅读标签到本轮男频公开目录的精确“组＋名称”映射。保留旧 optionId 和 conceptId；外部平台 ID 为新增映射数据。没有修改仓库 taxonomy 文件。

### v5-fanqie-title-evidence.json

五个官方榜单各前两位的 10 个标题样本，记录榜单 ID、频道、榜单类型、categoryId、位置、bookId、榜单截止文本、rankVersion、观察时间、详情页来源和摘要。它是工程可行性小样本，不是全平台命名效果统计。

## 4. 榜单的时间与指标

官方榜单的更新说明原文为：

> 排行榜每天下午3点前更新截止到上一日的排名数据

来源：公开榜单说明，[V5F09] https://fanqienovel.com/rank/1_1_257 。因此，产品应写“最新已获取的官方日榜样本”，不能把取样时刻表述成榜单的实时统计时刻。本轮五个榜单显示的统计截止均为 10-28 24:00。[V5F09][V5F10][V5F11][V5F12][V5F13]

官方榜单以在读数据排序，并有入榜门槛。阅读榜与新书榜的作品阶段不同。单一榜首在读数不能代表某题材的市场总量、竞争程度或新作者成功概率；也不能证明某种书名造成其热度。

抓取应分别记录 observedAt、statsCutoffRaw、可解析的 statsCutoff、rankVersion、书籍最新章节时间。页面没有统计日期时保留 unknown，不能拿抓取日或最新章节时间填充。

本轮原始返回同时含 readCount="0" 和 read_count 为实际榜单数字的情况。解析器应绑定经核验的 rank.book_list[].read_count，不能按大小写相似名称猜字段含义。

每一行的榜单和每一本的详情来源均在 title-evidence 与 sources JSON 中。不应从十本样本推导“番茄书名必须长”“必须开局”“必须惊叹号”。合理策略是按当前频道、主分类、作品阶段和作者偏好检索一个可比较样本集，再给不同表达形态的原创候选。

排行榜页书名可能包含私用区字体字符。本轮通过相同 bookId 的官方详情页 HTML title 得到正常文字，没有猜测替换字符或使用字体破解方案。生产解析器发现异常字符时，应换用已知公开详情来源；仍无法读取就标记不可用。[V5F09][V5F14 至 V5F23]

## 6. 推荐的书名证据闭环

1. 宿主读取当前作品的频道映射、主分类、已确认故事卖点、主角处境、作者保留词与禁用词，固定作品版本。
2. 定向取同类公开日榜样本，区分新书与阅读榜，保存榜单身份和统计截止时间。近邻题材仅作为显式补充。
3. 按 bookId 去重，关联官方详情页确认标题，记录缺失或不可读字段。初次可在小样本预算内工作，后续按质量和成本调整。
4. 模型提炼可观察的标题结构：长短、语气、身份信息、动作、反差、疑问和阅读承诺。不能把频率解释为因果成功公式。
5. 生成候选时，所有实质卖点绑定本书已确认内容或待采纳前提。为了吸睛增加的“无敌”“唯一”“灭世”等承诺必须有作品依据。
6. 候选分组保持差异，例如直给冲突、概念悬念、人物态度、氛围短题。组数和候选数量由当前操作合同决定，不强制每本书使用全部样式。
7. 宿主检查字符、已核验长度规则、重复、明显近似和来源。相似性检查说明其检索范围，不能宣称全网绝对唯一。
8. 模型审核标题与开篇、前期兑现窗口的对应关系。标题承诺进入作品承诺系统，后续可检查是否已兑现、延期或被剧情修订破坏。
9. 作者选择或已授权采纳后记录标题版本。随后剧情大改时，将标题标记为需复核，而不是自动改名。

固定命名任务由宿主直接准备证据，不额外启动一个模型决定“要不要联网”。数据抓取与缓存不是模型请求；样式分析是否合并到生成请求取决于上下文预算。刷新失败时使用最近成功快照，并清晰显示来源日期与降级状态，不用模型补造新榜单。

## 7. 目录更新与用户自由度

建议目录采用追加版本，包含来源 surface、频道、分组、平台 ID、别名、状态、采集时间和覆盖声明。刷新前后做新增、改名、停用、规则变更差异。现有作品固定原始选择及当时快照；新目录不静默改写旧作品。

内部创作题材与平台分类分离：用户可自由混搭、自定义、暂不选，保留原始文本。AI 对题材和体系的判断是建议，可说明依据及不确定项；用户可以关闭某个体系，或锁定自有世界规则。发布映射由宿主按当前平台规则检查，不能反向压缩作品的创作自由。

可采用公开书库 336 项作为当前有来源的阅读目录基础，作者端内容标签继续显示原种子来源与未完整核验状态，并允许导入作者提供的新快照。未来获得明确授权的作者页面核验时，再补齐那一范围，保留两套目录独立的规则。

## 8. 验证与限制

已执行：公开网页与前端资源读取；无登录分类返回提取；336 条公开阅读目录与37条榜单入口统计；154条现有男频标签精确映射；5个榜单与10个详情标题关联。

未执行：作者后台登录或发布；全部内容标签池核验；真实小说命名 A/B 试验；全榜单分页统计；标题点击率或销售因果分析；将新目录写入用户项目。

使用主来源：v5-fanqie-sources.json。中间抓取文件只供本轮研究，最终包建议使用规范化快照、交叉映射、标题元数据与此摘要，不包含全文网页或整套官方释义。
