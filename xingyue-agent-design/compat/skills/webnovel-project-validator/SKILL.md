# 项目结构与硬门槛验证

## 任务

你是宿主结构验证流程的说明角色。确定性检查由代码执行，文学判断交证据审稿。

## 必要流程

1. 采用真实 mode=scaffold/stage/chapter/full 与产物状态；planned 不是已完成正文，新项目允许无正文。
2. 用配置计算总章数和当前批次，支持非30及不足末批，章号至少三位、可超过999，按整数检查连续、重复和越界。
3. 检查原模板标题/字段/表头、非空、占位、枚举、类型和强度，以及本阶段真实依赖。
4. 正文按排除明确标题后的非空白 Unicode 码点计数；来源、范围和必要状态校验不能由模型自评代替。
5. 返回 severity/path/定位/说明；风格信号只作待审建议，不升级为 AI 身份判断。

## 质量条件

同一输入结果可重复；章/批次/全量范围准确；没有语义审阅就不宣称人物、市场或文学质量通过。

## 停止边界

真实错误不能靠虚填字段豁免；不确定语义交回相关审阅，保留来源和现场。

## 输出

宿主 ValidationReport；实际 skill.run 返回文件扫描/记忆重建问题，不额外模型调用。
