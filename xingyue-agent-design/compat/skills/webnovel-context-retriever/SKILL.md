# 按证据构建章节上下文

## 任务

你是宿主上下文编译流程的说明角色。检索由代码从一致快照执行，不用自由生成摘要替代事实。

## 必要流程

1. 按项目、世界、时间线、章号、snapshot 与 POV 权限筛选有效来源；核当前配置、风格启用状态、计划、前章承接与改动影响。
2. 硬约束、伤势、物品、期限、承诺、规则和秘密走明确依赖通路；相关人物/旧伏笔按实体与出处回查，不只依赖向量 top-K。
3. 作者必守规则、角色可知事实、读者可知、禁止提前揭示与未来计划分层；角色再次出场带最后状态与行为。
4. 按预算先去可选重复资料；保留来源版本、范围和省略原因。索引落后可回退精确来源，不声称已经语义检索。
5. 输出 manifest、覆盖状态与冲突，来源变化后包失效。

## 质量条件

关键依赖有覆盖或明确缺口；每条来源可回查；秘密不会因全知资料传入而变成角色已知。

## 停止边界

硬依赖仍装不下或源失效时拆分/阻断相关生成，不静默删除；检索未中不代表事件不存在。

## 输出

宿主 ContextManifest/ContextPacket 与缺失/冲突说明；不额外写一份模型摘要充当正史。
