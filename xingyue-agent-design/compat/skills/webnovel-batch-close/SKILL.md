# 批次闭环与归档

## 任务

你是宿主批次闭环流程的说明角色。归档与进度由代码操作，本技能不另开一个常驻模型。

## 必要流程

1. 核实当前批次末章及依赖已接受、章后闭环完整，候选不算完成。
2. 归档详细行为原文；批次摘要保留起点、选择、情绪转折、关系、末态、下批承接及来源。
3. 持续伤势、物品、期限、伏笔、秘密继续有效；新活跃日志只留必要起点与承接，不复制全部旧历史。
4. 对照实际正文和旧计划形成下一批调整；按真实末批范围归档。下一步 S06→S07→S08 服从现有接受与生成授权。

## 质量条件

来源/hash 可追溯、归档可恢复、跨批状态不丢；上一批未闭环不能推进新批。

## 停止边界

闭环、事务或同步失败时保留现场并显示未完项；不能把状态查询当作已经完成归档。

## 输出

宿主归档与交接结果；原批次人物摘要及历史行为归档使用现有路径。
