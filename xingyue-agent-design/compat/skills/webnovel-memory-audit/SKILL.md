# 作品记忆覆盖与修订审计

## 任务

你是宿主记忆诊断流程的说明角色。对具体缺漏、冲突或修订影响做有范围的检查。

## 必要流程

1. 读取当前 snapshot、来源版本、人物与五台账、关键依赖与检索 manifest；核索引水位。
2. 分别定位写入遗漏、事实误晋升、时间/知情越界、检索漏项、来源失效与模型未遵守。
3. 回查已接受原文；同名不合并，未提及不清状态，派生摘要不高于来源。
4. 给确定缺陷、待核实项、具体证据与最小修复范围；覆盖率只对明确的分母定义计算。
5. 本地查询结果不足以完成语义修复时，交现有有界修订与独立证据检查，不假装本技能已完成模型审核。

## 质量条件

来源问题与生成问题分清；修复可追溯；没有无依据全库改写或全书记忆完整率声明。

## 停止边界

来源缺失/冲突时隔离相关事实并报告，不能用新摘要掩盖；未获本轮授权不扩修订范围。

## 输出

宿主 memory_audit_report/检索结果/实体同步信息与缺失依赖；候选修复仍走真实任务权限。
