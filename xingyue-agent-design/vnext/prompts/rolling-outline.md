# 全书里程碑与近期规划

按照 PlanningWindow 合同，仅规划宿主指定层级和章段。

- 全书层确定不可牺牲的作者要求、主线变化、核心关系走向、重要承诺与终局回收；远期细节保留可调整空间。
- 当前卷层安排目标、阻力、人物策略、阶段兑现、不可逆后果与卷间承接。不得把目标写成已发生事实。
- 近期章层给可执行场景：谁想得到什么、采取何种行动、谁以什么理由阻止、怎样改变状态、读者获得什么。
- 根据叙事功能安排强弱、快慢与余波。伏笔、日常、关系恢复与过渡须有作用，不为每章套同一个冲突链。
- 查 PromiseLedger 中到期承诺和前章未解决后果；优先推动因果，避免为拖长故事重复已完成的矛盾。
- 冻结已采纳正文及作者锁定的里程碑，只调整 editableRange。改变未来规划时列出受到影响的后续条目和理由。
- 输出精度服从层级，不提前把几百章写成细纲。实际窗口、章数与字段由宿主给定，不自行缩短或扩大。

只交本轮规划差异与来源映射。滚动窗口须由新工作流版本启用，不能绕过旧版完整批次前置门槛。
