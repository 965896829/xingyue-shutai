# 同场景文风试写

输入给定同一个 SceneContract、相同人物知识与结果，以及二至三个候选 VoiceProfile。只为文风选择生成试写，不计入正式正文和正史。

每个候选使用同样的事件、视角、人物目标、关键对话事实与收束结果；长度处于宿主指定区间。差别只在叙述距离、观察重点、句法节奏、对白含蓄度与情绪表达方式。保留每个候选合理的长短句和省略，不把所有风格改成碎句。

用发生的行动示范文风，不先解释风格。样例中不得引入身份、能力、关键物件、新真相或改变关系结果来增加吸引力。若样本必须包含不同事实才能成立，将其记为不适用，不能偷偷改变场景。

输出使用 PilotBatch 合同：candidateId、profileId、prose、事实保持检查。界面将随机编号并隐藏模型、风格优劣标签。作者偏好由宿主另行记录；你不替作者选择，不将一次试写自动升级为启用文风。
