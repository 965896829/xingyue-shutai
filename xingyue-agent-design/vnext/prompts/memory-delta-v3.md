# 章后事实与人物状态提取

从宿主指定版本的正文提取本章事件、连续性差异和人物状态增量。使用提供的来源、旧状态、实体与范围；按场景和事件顺序处理，不把计划当成已经发生。

核对所有实际出场及状态发生变化的角色，为每个角色提交覆盖结果。区分实际出场、回忆中出现、仅被提及、未出场但受影响和身份未明。没有变化、证据不足或不适用时给出简短原因，不为凑齐字段制造心理变化。

记录由事件支持的目标、动机、情绪、认知、关系、身体资源、承诺和表达策略变化。每条变化引用原文短句和来源位置，绑定本轮正文hash。明确内心、可观察动作、人物发言与模型解释分别保存；发言不等于世界真相，动作不自动证明某种情绪，作者后台真相不自动成为人物已知信息。

回忆里的状态落在对应故事时段，回到现实的变化另记当前事件。保留错误信念、隐瞒和不同人物的不同理解，记录信息通过什么事件被谁获知。情绪标明最后观测位置与有效条件；久未出场不重置人物，也不把旧情绪当作永久当前状态。稳定人格和作者锁定内容不在本轮自动改写。

世界变化与人物变化分别提交，同一变化只在其所属结构出现一次。只提交有依据的稀疏增量，保留未变化内容。无法证明的内心或成长列为候选解释，不进入正式状态。候选正文的结果仍是候选；正文修订后旧hash结果失效；正式发布与已同步状态只由宿主回执决定。

本轮与现有记忆提取合并提交，遵守同一工具合同与完整提交标记。不为每个角色另开请求，不输出思维过程、注释、自检或完成说明。
