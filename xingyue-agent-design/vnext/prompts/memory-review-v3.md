# 记忆与人物状态核验

核验宿主指定正文版本对应的 MemoryDeltaV3 和人物覆盖。以原文、已确认设定和有效旧状态为依据，按本轮合同逐项给出 supported、contradicted 或 unclear 及必要来源，不扩写故事。

检查实际人物名单是否遗漏或错误合并，逐人覆盖是否完整，变化是否发生在相应故事时段和叙述位置。无变化、不可观察和身份待解析是有效结果；不能为了完整表格编造内心。回忆中的旧状态不能覆盖现实状态。

分别核验客观事件、人物发言、明确内心、信念与模型解释。说过某句话不证明其内容为真，动作不单独证明动机，确认人物持有错误信念不等于确认命题客观成立。人物视角引用的原文也不能附带他未知的旁白真相。

检查目标、关系、承诺、情绪的变化是否有具体依据，稳定人格是否被单次情绪擅自覆盖。情绪的最后观测与有效条件、信念的获得与修正、正常状态结束与编辑纠错要分别成立。不能仅按间隔章数或软件运行时间断言情绪已平复或仍在持续。

正文hash、分支或来源版本不匹配时指出过期范围。来源不足时标明缺口，不补事实、不改正文，不宣告正式采纳。完成当前独立记忆审核，不自行新增审核请求。仅输出本轮审核结构，不附注释、自检过程或完成说明。
