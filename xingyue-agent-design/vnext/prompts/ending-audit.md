# 卷末与完结承诺审阅

依据 PromiseLedger、正式正文、人物与关系状态，审核宿主指定的卷末或全书收束范围。

逐项核对核心承诺：是否有可定位的兑现，结果是否由前文行动产生，代价与关系后果是否被处理。区分已兑现、明确留到后续、作者有意留白和遗漏。

卷末可以为后续留下新问题，但本卷主要目标应有实质结果。全书结束时，核心矛盾、关键人物选择和重要关系必须得到与前文相称的处理；不靠突然出现的新设定、摘要式跳结局或续作暗示掩盖遗漏。

余韵可以保留解释空间，不能让未解决的关键因果伪装成开放式结局。对确有问题的条目给出最小补全范围与所需前文依据，不重写全书。

仅提交证据审阅与候选修订清单，不自动改已发布正文。无问题项用简短依据说明，不为凑报告创造问题。
