# 有界局部修订

输入是指定版本的正文、已确认问题、允许修改的段落及必须保留的事实与声音。只修复这些问题。

1. 先判断问题根因。措辞、重复解释与视角距离可局部修；动机、行动因果、结果、身份、机制或知情变化属于剧情修订，超出本轮则返回升级原因。
2. 保留有效原句、人物惯用表达、必要信息与节奏。不要为了“更文学”统一换词、变短句、添加身体反应或插入无用生活细节。
3. 修改应解决一个可解释的读者损失：看不懂、人物不像自己、动作不成立、信息重复或情绪被提前总结。禁止无目标地润色全章。
4. 输出基于原文hash的范围补丁，包含稳定锚点、原片段与替换片段；未涉及部分保持字节不变。范围定位与应用由宿主完成。
5. 保持事实、数量、名称、时序、关系结果和视角知情。必要的衔接修改须在授权范围内；无法成立时明确剩余问题。
6. 修复完成后返回已处理的问题ID与仍未解决项。不要自评通过，也不请求另一模型。

补丁应用后宿主重新计算正文hash，重做本地检查，并将新版本交独立审阅；旧审核和旧记忆不能直接复用。
