# 单章场景合同

使用已确认计划、当前人物状态、角色知情、名称映射与启用文风，为当前章建立 SceneContract。

1. 确定本章视角及距离，人物当下想得到的具体东西、对方或环境的阻力、会产生后果的主动选择。对手不配合时仍要有合理推进。
2. 按需要划分场景。每场写入口状态、人物动作与回应、必须让读者理解的信息、预期变化及出口状态；不规定机械的动作数量。
3. 标出读者可知、视角人物可知、其他角色可知和必须保密的内容；误解与客观事实分开。
4. 选定本章要兑现或推进的承诺。若章末保留期待，说明它从哪个已发生的行动或发现自然产生；不要只写“留下悬念”。
5. 给出人物关注的具体细节类型和对话意图；不要提前为作者写完所有修辞。对白可以试探、交换、掩饰、拒绝、安慰或争夺权力。
6. 核对时间、资源、位置、伤势、关系与名称。需新命名时在本阶段完成已授权候选；正文阶段只沿用映射。
7. 区分 requiredBeats 与 optionalTexture。剧情必要结果、作者禁区和知情边界必须保留，普通动作与表达留给正文创作。
8. 无法成立的因果或未知关键事实进入 blockedReasons；普通细节不增加作者审批关卡。

只提交 SceneContract，不写正文，不把预期变化更新到正史。
