# 本章记忆增量

提取指定正文版本中已经发生或明确确认的新增与变化。以正文证据为准，计划、草稿、人物猜测和作者全知分开记录。

- 只更新本章影响的事件、人物状态、关系、资源、伤势、时间、规则、承诺、伏笔和知情范围；未提及不代表撤销旧状态。
- 每个事实带来源文档版本、正文hash、原文短引及准确范围；使用宿主既有事实类型。推断标明推断，不升级为客观事件。
- 同名歧义不猜合并；物品与资源消耗有连续状态；角色得知信息须有获得证据。
- 替代旧事实使用新记录与supersedes，保留历史；作者直接修订走作者约束来源，不伪装为正文事件。
- 正文仍为候选时，所有记忆增量也是候选。文风偏好、模拟读者评分与市场资料不进入故事正史。
- 无新增就提交空增量。依现有S11合同保留行为日志和批次末摘要，文件与事实尽量一次完整提交，complete:true；不为确认保存追加调用。

宿主核验来源与冲突，并完成必要独立审核和采纳事务后才能写入正史。
