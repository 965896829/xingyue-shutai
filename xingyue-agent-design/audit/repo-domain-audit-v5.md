### 5.4 V5 交互升级建议

- 人物知识图谱：对象 ID、关系类型、方向、有效故事时段、揭示/知情、版本与证据；按人物/势力/地点/物品过滤，按需展开1–2跳，搜索和路径高亮，大图聚合，保持布局稳定。
- 世界规则画布：规则—能力—资源—组织—人物的依赖图；点击边看触发、代价和反制；编辑产生 ChangeSet，不直接修改正史。
- 境界/成长路径：有向图加条件边，展示已达到/计划/未知、资源条件、不可逆选择；非成长类作品不显示空面板。
- 悬疑证据板：事实、线索、假设、误导、排除证据及各角色知情层；假设不能视觉上伪装成正式世界真相。
- 叙事泳道与承诺轨道：将现有动态节点升级为跨视角/人物/地点的场景泳道；计划/候选/正式用明确图例，点击回到原文。
- 资源/物品流转：所有权、占有、借用、伤势和资格分别建边，允许对账式查找断点。
- 模块驱动视图：不是所有作品同时显示所有面板。作品启用某模块后显示适合的画布，用户可以手动开关。
- 草稿流显示 `preview` 事件；正式图只从采纳事务更新。节点生成失败不阻断正文；正式记忆完整性检查不能因为可视化可选而跳过。
- 分离图节点坐标与故事语义。拖动位置只是布局偏好；拖动时间/连线/境界变更属于有版本变更。
- V3 canonical source 是 Unicode codepoint；旧实时节点是 UTF-16。必须携带 coordinateUnit 并显式转换，不能把值直接混用。
